# 4.7 Operator Precedence

Operator precedence decides how expressions group when parentheses are not used.

```pilang
println(1 + 2 * 3);   // 7
println((1 + 2) * 3); // 9
```

## Precedence Table

From highest to lowest:

| Level | Operators |
| --- | --- |
| 1 | member access `.`, indexing `[]`, calls `()` |
| 2 | unary `+`, unary `-`, `!`, `~`, `#`, `++`, `--`, `typeof` |
| 3 | exponent `**` |
| 4 | `*`, `/`, `%` |
| 5 | dot product `@`, `*.` |
| 6 | `+`, `-` |
| 7 | comparisons `==`, `!=`, `>`, `<`, `>=`, `<=`, `is` |
| 8 | shifts `<<`, `>>`, `>>>` |
| 9 | bitwise AND `&` |
| 10 | bitwise XOR `^` |
| 11 | bitwise OR `|` |
| 12 | ranges `..`, `..:step` |
| 13 | membership `in` |
| 14 | logical AND `&&` |
| 15 | logical OR `||` |
| 16 | conditional `? :` |
| 17 | assignment `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `|=`, `^=`, `&=` |

## Notes

Use parentheses when an expression mixes several operator families.

```pilang
let value = (a + b) * (c - d);
```

Exponentiation parses recursively on the right.

```pilang
println(2 ** 3 ** 2); // 2 ** (3 ** 2)
```

Comparison chains are combined with logical AND.

```pilang
println(1 < x < 10);
```
