# 4.1 Arithmetic Operators

Arithmetic operators work on numbers and, for some operators, on collections, strings, tuples, sets, and tensors.

## Numeric Arithmetic

```swift
let a = 10;
let b = 3;

println(a + b);  // 13
println(a - b);  // 7
println(a * b);  // 30
println(a / b);  // 3.333...
println(a % b);  // 1
println(a ** b); // 1000
```

Division by zero returns `INF`. Modulo by zero returns `NAN`.

```swift
println(1 / 0); // INF
println(1 % 0); // NAN
```

## Unary Numeric Operators

```swift
println(+10); // 10
println(-10); // -10
println(~10); // bitwise negation
```

`++` and `--` can be used before or after an assignable target.

```swift
let i = 0;
i++;
++i;
i--;
--i;
```

## Strings

`+` concatenates strings. If either side prefers string conversion, Pilang converts the values and joins their text.

```swift
println("Pi" + "lang"); // Pilang
println("count: " + 3); // count: 3
```

`*` repeats a string by the number on the right.

```swift
println("ha" * 3); // hahaha
```

`-` removes all occurrences of the right string from the left string.

```swift
println("banana" - "na"); // ba
```

## Lists

`+` appends the right value as one item to the list on the left and returns the same list.

```swift
let values = [1, 2];
values + 3;
println(values); // [1, 2, 3]
```

If the right value is also a list, that list is appended as a single nested item. Use spread syntax when you want to merge items into a new list.

```swift
let values = [1, 2];
values + [3, 4];
println(values); // [1, 2, [3, 4]]

println([1, 2, ...[3, 4]]); // [1, 2, 3, 4]
```

`-` removes the first matching value from a list.

```swift
let values = [1, 2, 3, 2];
values - 2;
println(values); // [1, 3, 2]
```

`*` repeats a list by the number on the right.

```swift
println([1, 2] * 3); // [1, 2, 1, 2, 1, 2]
```

When both operands are numeric matrix-shaped lists, `*` performs matrix multiplication.

```swift
let a = [[1, 2], [3, 4]];
let b = [[5, 6], [7, 8]];
println(a * b);
```

## Tuples

`+` concatenates two tuples.

```swift
println((1, 2) + (3, 4)); // (1, 2, 3, 4)
```

`*` repeats a tuple by a number. The number can be on either side.

```swift
println(("x",) * 3); // (x, x, x)
println(3 * ("x",)); // (x, x, x)
```

## Tensors

`+`, `-`, `*`, and `/` support tensor-to-tensor operations and tensor-to-scalar operations through the tensor runtime.

```swift
import tensor;

let a = tensor.ones([2, 2]);
println(a + 3);
```

## Vector Operators

Use `@` or `*.` for dot product between numeric lists of the same length.

```swift
println([1, 2, 3] @ [4, 5, 6]);
println([1, 2, 3] *. [4, 5, 6]);
```

Use `^` between two 3-item numeric lists for cross product.

```swift
println([1, 0, 0] ^ [0, 1, 0]); // [0, 0, 1]
```

## Special-Case Summary

| Operator | Left operand | Right operand | Behavior |
| --- | --- | --- | --- |
| `+` | number | number | numeric addition |
| `+` | string-like | any value | string concatenation after conversion |
| `+` | list | any value | append the right value as one item |
| `+` | tuple | tuple | tuple concatenation |
| `+` | tensor | tensor or number | tensor addition or scalar addition |
| `-` | number | number | numeric subtraction |
| `-` | string | string-like | remove all right-side substrings |
| `-` | list | any value | remove the first matching item |
| `-` | set | set | set difference |
| `-` | tensor | tensor or number | tensor subtraction or scalar subtraction |
| `*` | number | number | numeric multiplication |
| `*` | string | number | repeat string |
| `*` | list | number | repeat list |
| `*` | numeric matrix list | numeric matrix list | matrix multiplication |
| `*` | tuple | number | repeat tuple |
| `*` | number | tuple | repeat tuple |
| `*` | tensor | tensor or number | tensor multiplication or scalar multiplication |
| `/` | number | number | numeric division, `1 / 0` gives `INF` |
| `/` | tensor | tensor or number | tensor division or scalar division |
| `%` | number | number | integer remainder, modulo by zero gives `NAN` |
| `**` | number | number | exponentiation |
| `@`, `*.` | numeric list | numeric list | dot product |
| `^` | 3-item numeric list | 3-item numeric list | cross product |
| `&` | set | set | set intersection |
| `|` | set | set | set union |
| `^` | set | set | set symmetric difference |
