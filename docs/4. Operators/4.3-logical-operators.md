# 4.3 Logical Operators

Logical operators work with truthiness and return booleans. This page also covers related expression operators that are often used in conditions and calls: `in`, `is`, `...`, and `<-`.

## Logical Operators

| Operator | Example | Meaning |
| --- | --- | --- |
| `&&` | `a && b` | logical AND |
| `||` | `a || b` | logical OR |
| `!` | `!value` | logical NOT |

This page also covers operators that are commonly used in conditional
expressions, even though they are not all logical operators in the strict sense.

| Operator | Example | Meaning |
| --- | --- | --- |
| `in` | `item in collection` | membership test |
| `is` | `value is Prototype` | prototype-chain test for map/object values |
| `...` | `fn(...args)` | spread iterable values in calls or literals |
| `<-` | `name <- expression` | assign and produce the assigned value |

```pilang
println(true && true);  // true
println(true && false); // false
println(false || true); // true
println(!false);        // true
```

`!` works on any value through Pilang truthiness.

```pilang
println(!nil);   // true
println(!false); // true
println(!0);     // true
println(!1);     // false
```

Falsey values include:

- `false`
- `nil`
- numeric `0`
- empty strings, such as `""`
- empty lists, such as `[]`
- empty maps, such as `{}`
- tensors with size `0`
- modules with no exports
- ranges whose start and end are the same, such as `1..1`

Other values are truthy according to their runtime type.

## Evaluation

`&&` and `||` are binary operators in the current runtime. Both operands are evaluated before the operator is applied.

```pilang
left() && right(); // both calls are evaluated
```

Use `if` when the right side must only run conditionally.

```pilang
if ready {
    run();
}
```

## Membership: `in`

`in` checks whether the left value belongs to the right value.

```pilang
println(2 in [1, 2, 3]);          // true
println("lang" in "Pilang");      // true
println("name" in {"name": "Ada"}); // true
println(4 in 0..10:2);            // true
println("read" in {"read", "write"}); // true
```

For maps, `in` checks keys. For strings, it checks substring containment. For ranges, it checks numeric range membership. For other iterable values, it scans the iterable.

## Prototype Test: `is`

`is` checks whether the left map/object is the right prototype, an instance of
the right prototype, or derives from the right prototype through its prototype
chain.

```pilang
class Animal {
}

class Dog : Animal {
}

let dog = Dog();

println(dog is Dog);    // true
println(dog is Animal); // true
println(dog is Object); // true
```

The right side should be a prototype object, usually a class value or a
map-defined prototype. If either side is not a map/object, `is` returns `false`.

```pilang
println(10 is Object);     // false
println("pi" is Object);   // false
println([1, 2] is Object); // false
```

For primitive type checks, use `typeof`, `Object.type(value)`, or the `type`
module instead of `is`.

## Spread: `...`

The spread operator expands iterable values in calls and literals.

### Call Spread

Use `...` to pass a list of positional arguments into a function call.

```pilang
fun add(a = 0, b = 0, c = 0) {
    return a + b + c;
}

let args = [1, 2, 3];
println(add(...args)); // 6
```

When using named arguments, positional and spread arguments must come before named arguments.

### List Spread

Use `...` inside list literals to extend the new list with another iterable.

```pilang
let left = [1, 2];
let right = [3, 4];

println([0, ...left, ...right]); // [0, 1, 2, 3, 4]
```

### Map Spread

Use `...` inside map literals to copy entries from another map.

```pilang
let base = {"theme": "dark"};
let settings = {...base, "debug": true};

println(settings["theme"]); // dark
```

## Left Arrow: `<-`

`<-` is a walrus-style assignment expression.

```pilang
if value <- read_value() {
    println(value);
}
```

It assigns the expression on the right to the name on the left, then leaves that assigned value as the result of the expression. This is useful when you want to compute, store, and immediately test a value.

```pilang
while line <- next_line() {
    println(line);
}
```

Chained `<-` expressions are not allowed.

```pilang
// Invalid
a <- b <- c;
```
