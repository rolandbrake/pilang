# 4.2 Comparison Operators

Comparison operators return booleans.

```swift
println(1 == 1); // true
println(1 != 2); // true
println(3 > 2);  // true
println(3 >= 3); // true
println(2 < 3);  // true
println(2 <= 2); // true
```

## Equality

`==` and `!=` compare values.

```swift
println("a" == "a");
println([1, 2] == [1, 2]);
println(nil == nil);
```

Numbers, booleans, strings, tuples, ranges, and sets have direct comparison behavior. Objects can customize equality with an `equals(other)` method.

## Ordering

`>`, `<`, `>=`, and `<=` compare ordered values.

```swift
println(10 > 5);
println("b" > "a");
```

String ordering uses lexicographic comparison.

## Chained Comparisons

Pilang supports chained comparisons. The chain is combined with logical AND.

```swift
println(1 < 2 < 3); // true
println(1 < 2 > 3); // false
```

## Set Comparisons

Sets support equality and subset/superset comparisons.

```swift
let small = {1, 2};
let big = {1, 2, 3};

println(small < big);  // proper subset
println(small <= big); // subset
println(big > small);  // proper superset
println(big >= small); // superset
```

## Membership

`in` tests membership.

```swift
println(2 in [1, 2, 3]);
println("lang" in "Pilang");
println("name" in {"name": "Ada"});
println(4 in 0..10:2);
println("read" in {"read", "write"});
```

For maps, `in` checks whether the left operand is a key.

## Prototype Test

`is` checks the prototype chain for map/object values. It returns `true` when
the left value is the same prototype as the right value, an instance created from
the right prototype, or a value whose prototype chain eventually reaches the
right prototype.

```swift
class Animal {
}

class Dog : Animal {
}

let dog = Dog();

println(dog is Dog);    // true
println(dog is Animal); // true
println(dog is Object); // true
```

Class values are prototype objects, so `is` can also compare class/prototype
objects directly.

```swift
println(Dog is Animal); // true
println(Dog is Object); // true
```

For map-defined prototypes, use `Object.extends(parent, child)` to connect the
prototype chain.

```swift
let Entity = {
    tag: "entity"
}

let Player = {
    name: "player"
}

Object.extends(Entity, Player);

let player = Player();

println(player is Player); // true
println(player is Entity); // true
```

`is` is not a general primitive type test. If either operand is not a map/object,
it returns `false`.

```swift
println(10 is Object);       // false
println("pi" is Object);     // false
println([1, 2] is Object);   // false
```

Use `typeof`, `Object.type(value)`, or the `type` module when you need to inspect
primitive or collection types.
