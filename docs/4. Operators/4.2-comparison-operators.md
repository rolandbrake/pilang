# 4.2 Comparison Operators

Comparison operators return booleans.

```swift
println(1 == 1); // true
println(1 != 2); // true
println(3 > 2);  // true
println(3 >= 3); // true
println(2 < 3);  // true
println(2 <= 2); // true
```

## Equality

`==` and `!=` compare values.

```swift
println("a" == "a");
println([1, 2] == [1, 2]);
println(nil == nil);
```

Numbers, booleans, strings, lists, tuples, ranges, and sets have direct comparison behavior. List equality is structural: lists must have the same length and corresponding elements are compared recursively. Objects can customize equality with an `equals(other)` method.

```swift
println([1, 2, [3, 4]] == [1, 2, [3, 4]]); // true
println([1, 2] == [1, 3]);                 // false
println([1, 2] == [1, 2, 3]);              // false
```

## Ordering

`>`, `<`, `>=`, and `<=` compare ordered values.

```swift
println(10 > 5);
println("b" > "a");
```

String ordering uses lexicographic comparison.

## Chained Comparisons

Pilang supports chained comparisons. The chain is combined with logical AND.

```swift
println(1 < 2 < 3); // true
println(1 < 2 > 3); // false
```

## Set Comparisons

Sets support equality and subset/superset comparisons.

```swift
let small = {1, 2};
let big = {1, 2, 3};

println(small < big);  // proper subset
println(small <= big); // subset
println(big > small);  // proper superset
println(big >= small); // superset
```

## Membership

`in` tests membership.

```swift
println(2 in [1, 2, 3]);
println("lang" in "Pilang");
println("name" in {"name": "Ada"});
println(4 in 0..10:2);
println("read" in {"read", "write"});
```

For maps, `in` checks whether the left operand is a key.

## Prototype Test

`is` checks class inheritance. It returns `true` when the left value is the same
class as the right value, an instance of the right class, or an instance whose
class derives from the right class.

```swift
class Animal {
}

class Dog : Animal {
}

let dog = Dog();

println(dog is Dog);    // true
println(dog is Animal); // true
println(dog is Object); // true
```

Class values are prototype objects, so `is` can also compare class/prototype
objects directly.

```swift
println(Dog is Animal); // true
println(Dog is Object); // true
```

Only classes and class instances participate in inheritance checks. Primitive
maps, lists, tuples, and other values are not class instances.

`is` is not a general primitive type test. If either operand is not a class or
class instance,
it returns `false`.

```swift
println(10 is Object);       // false
println("pi" is Object);     // false
println([1, 2] is Object);   // false
```

Use `typeof`, `Object.type(value)`, or the `type` module when you need to inspect
primitive or collection types.
