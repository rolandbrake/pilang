# 4.5 Special Operators

Special operators cover bitwise operations, ranges, type inspection, indexing, calls, member access, and conditional expressions.

## Bitwise Operators

Bitwise operators coerce numeric operands to integers.

```pilang
println(6 & 3);   // 2
println(6 | 3);   // 7
println(6 ^ 3);   // 5
println(1 << 3);  // 8
println(8 >> 1);  // 4
println(-1 >>> 1); // unsigned right shift
println(~6);
```

For lists, bitwise and shift operators can apply the numeric operation to each list item when the right operand is numeric.

```pilang
println([1, 2, 3] << 1); // [2, 4, 6]
```

For sets:

```pilang
println({1, 2} | {2, 3}); // union
println({1, 2} & {2, 3}); // intersection
println({1, 2} ^ {2, 3}); // symmetric difference
println({1, 2} - {2});    // difference
```

## Iterable Arithmetic Cases

Some arithmetic operators have collection-specific meanings:

```pilang
let values = [1, 2];
values + 3;          // append one item
println(values);     // [1, 2, 3]

println([1, 2] * 2); // [1, 2, 1, 2]
println("ha" * 3);   // hahaha
println((1, 2) * 2); // (1, 2, 1, 2)
```

For lists, `+` appends the right operand as a single item. To expand another iterable into a list, use spread:

```pilang
println([1, 2, ...[3, 4]]); // [1, 2, 3, 4]
```

## Length Operator

`#` returns the size of supported collection-like values.

```pilang
println(#"Pilang");
println(#[1, 2, 3]);
println(#{"name": "Ada"});
```

For tensors, `#` returns the first dimension size, or `0` for a scalar tensor.

## Type Operator

`typeof` returns the runtime type name as a string.

```pilang
println(typeof 123);      // number
println(typeof "hello");  // string
println(typeof [1, 2]);   // list
```

## Range Operator

`..` creates a numeric range. Add `:step` to control the increment.

```pilang
println(1..5);
println(0..10:2);
```

Ranges are commonly used in `for` loops.

```pilang
for i in 0..5 {
    println(i);
}
```

## Slice Operator

Use `:` inside brackets to create slices.

```pilang
items[start:stop];
items[start:stop:step];
items[:stop];
items[start:];
items[::step];
```

Slices work on lists, tuples, and strings.

## Conditional Operator

`condition ? then_value : else_value` chooses between two expressions.

```pilang
let label = score >= 60 ? "pass" : "fail";
```

## Member, Index, And Call Operators

```pilang
object.field;
object["field"];
items[0];
function_name(arg1, arg2);
```

Indexing wraps around sequence length for lists, tuples, and strings.
