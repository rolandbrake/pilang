# 4.4 Assignment Operators

Assignment stores a value in an assignable target.

```pilang
let value = 1;
value = 2;
```

Valid targets include variables, list items, map entries, object fields, and supported indexed values.

```pilang
name = "Pilang";
items[0] = "first";
object.field = 42;
object["field"] = 42;
```

## Compound Assignment

Compound assignment reads the current value, applies an operator, and stores the result.

```pilang
let n = 10;

n += 5;
n -= 2;
n *= 3;
n /= 4;
n %= 5;
```

The parser also accepts bitwise compound assignment forms:

```pilang
flags |= 1;
flags ^= 2;
flags &= 3;
```

For the clearest current behavior, prefer explicit bitwise reassignment:

```pilang
flags = flags | 1;
flags = flags ^ 2;
flags = flags & 3;
```

The lexer recognizes additional assignment-like tokens such as `**=`, `<<=`, `>>=`, `>>>=`, and `@=`, but the current parser does not handle them as assignment expressions. Write those operations explicitly instead.

```pilang
power = power ** 2;
value = value << 1;
dot = left @ right;
```

## Increment And Decrement Assignment

`++` and `--` update an assignable target by one.

```pilang
let i = 0;

i++;
++i;
i--;
--i;
```

Prefix and postfix forms both store the updated value. The postfix form leaves the original value as the expression result before storing the update.

## Chained Assignment

Assignment expressions can be chained.

```pilang
let a, b, c;
a = b = c = 0;
```

## Destructuring Assignment

List-style destructuring assigns items from one right-hand value into several
left-hand names.

```pilang
[x, y] = [10, 20];
println(x);
println(y);
```

The same form works with function results. A common pattern is to return a list
from a helper and unpack it immediately at the call site.

```pilang
fun bounds(values) {
    return [min(values), max(values)];
}

[low, high] = bounds([4, 2, 9]);

println(low);
println(high);
```

The left-hand brackets are not a list literal in this context. They describe
assignment targets. Pilang evaluates the right-hand expression once, then stores
the first item into the first name, the second item into the second name, and so
on.

```pilang
fun pair(a, b) {
    return [a, b];
}

[left, right] = pair("L", "R");
```

The left side must contain identifiers.

```pilang
[a, b] = [1, 2];       // valid
// [items[0], b] = [1, 2]; // invalid
```

Declare names with `let` first when you want to make the local/module intent
explicit, or assign directly when normal assignment should create or update the
names according to the current scope rules.

```pilang
let a, b;
[a, b] = [1, 2];
```

## Slice Assignment

List slices can be assigned from a list or tuple. The source length must match for extended slice assignment.

```pilang
let values = [0, 1, 2, 3];
values[1:3] = [10, 20];
println(values); // [0, 10, 20, 3]
```
