# 5.5 Continue

`continue` skips the rest of the current loop iteration.

```pilang
let values = [1, nil, 3];

for value in values {
    if value == nil {
        continue;
    }
    println(value);
}
```

## In While Loops

In a `while` loop, `continue` jumps back to the condition check.

```pilang
let i = 0;

while i < 10 {
    i++;

    if i % 2 == 0 {
        continue;
    }

    println(i);
}
```

This prints only odd numbers.

## In For Loops

In a `for` loop, `continue` jumps to the next item from the active iterator.

```pilang
for i in 0..10 {
    if i % 2 == 0 {
        continue;
    }

    println(i);
}
```

## Nested Loops

`continue` applies to the innermost loop.

```pilang
for row in 0..3 {
    for col in 0..3 {
        if col == 1 {
            continue;
        }
        println(row + ", " + col);
    }
}
```

## Placement Rules

`continue` can only appear inside a loop. Using it outside a loop is a parser error.

```pilang
// Invalid
continue;
```

`continue` must be followed by a statement delimiter: a semicolon, newline, closing brace, or end of file.

```pilang
if skip {
    continue
}
```

## Unreachable Code

Inside a braced block, code after `continue` in the same block is unreachable and may be reported as an error.

```pilang
let items = [1, 2, 3];

for item in items {
    continue;
    println("unreachable");
}
```
