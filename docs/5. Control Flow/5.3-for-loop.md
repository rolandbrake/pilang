# 5.3 For Loop

Pilang `for` loops iterate over iterable values.

```swift
for item in [1, 2, 3] {
    println(item);
}
```

The loop variable is scoped to the loop body.

## Syntax

Parentheses are optional.

```swift
let values = [1, 2, 3];

for item in values {
    println(item);
}

for (item in values) {
    println(item);
}
```

The left side may be one identifier, or two identifiers separated by a comma.
With one identifier, the loop variable receives each value, except maps where it
receives each key. With two identifiers, the first receives the index or key and
the second receives the value.

```swift
for i in 0..5 {
    println(i);
}

for i, value in ["a", "b", "c"] {
    println(i + ": " + value);
}
```

## Single-Statement Bodies

If the body is one statement, braces are optional.

```swift
for i in 0..5
    println(i);
```

## Ranges

Ranges are a common iterable for numeric loops.

```swift
for i in 0..5 {
    println(i); // 0, 1, 2, 3, 4
}
```

The range end is exclusive during iteration. Add a step with `:`.

```swift
for i in 0..10:2 {
    println(i); // 0, 2, 4, 6, 8
}

for i in 5..0:-1 {
    println(i); // 5, 4, 3, 2, 1
}
```

## Lists, Tuples, Strings, Sets

Lists and tuples yield their items.

```swift
for value in [10, 20, 30] {
    println(value);
}

for value in ("a", "b", "c") {
    println(value);
}
```

Strings yield one-character strings.

```swift
for ch in "abc" {
    println(ch);
}
```

Sets are iterable, but their order is not guaranteed.

```swift
for value in {"red", "green", "blue"} {
    println(value);
}
```

## Maps

Maps yield keys in one-variable loops. Use the key to access the value, or use
two variables to receive each key and value directly.

```swift
let user = {"name": "Ada", "active": true};

for key in user {
    println(key + ": " + user[key]);
}

for key, value in user {
    println(key + ": " + value);
}
```

## Nested For Loops

Loops can be nested.

```swift
for row in 0..3 {
    for col in 0..3 {
        println(row + ", " + col);
    }
}
```

`break` and `continue` apply to the nearest enclosing loop.
