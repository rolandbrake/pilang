# 5.1 If / Else / Elif

`if`, `elif`, and `else` choose which branch of code to run.

```pilang
let score = 75;

if score >= 90 {
    println("excellent");
} elif score >= 60 {
    println("pass");
} else {
    println("fail");
}
```

## Conditions

Conditions are expressions. Parentheses are optional.

```pilang
let ready = true;

if ready {
    println("ready");
}

if (ready) {
    println("also ready");
}
```

Pilang uses truthiness for conditions. Falsey values include:

- `false`
- `nil`
- numeric `0`
- empty strings, such as `""`
- empty lists, such as `[]`
- empty maps, such as `{}`
- tensors with size `0`
- modules with no exports
- ranges whose start and end are the same, such as `1..1`

Other values are truthy according to their runtime type.

```pilang
if !"" {
    println("empty strings are falsey");
}
```

## Braced Blocks

Use `{}` for a multi-statement branch.

```pilang
if count > 0 {
    println("counting");
    count -= 1;
}
```

Block variables declared with `let` are scoped to the block.

```pilang
if enabled {
    let message = "enabled";
    println(message);
}

// message is not available here
```

## Single-Statement Branches

If a branch body is one statement, braces are optional.

```pilang
if count > 0
    println(count);
```

Single-line forms also work.

```pilang
if count > 0 println(count);
```

This style is concise, but braces are clearer when the body might grow.

## Elif Chains

Use `elif` for additional tests. Branches are checked in order.

```pilang
let value = 4;

if value < 0 {
    println("negative");
} elif value == 0 {
    println("zero");
} elif value < 10 {
    println("small");
} else {
    println("large");
}
```

Only the first matching branch runs.

## Else

`else` runs when no previous branch matched.

```pilang
let logged_in = false;

if logged_in {
    println("welcome");
} else {
    println("please sign in");
}
```

## Nested Conditions

Conditions can be nested.

```pilang
let user = {"name": "Ada", "active": true};

if user != nil {
    if user.active {
        println(user.name);
    }
}
```

When nesting single-statement branches, use braces to avoid ambiguity.

## Conditional Expressions

For choosing between two values, use the conditional expression operator.

```pilang
let score = 75;
let label = score >= 60 ? "pass" : "fail";
```

Use `if` statements for control flow. Use `? :` when you need a value.
