# 5.6 Return

`return` exits the current function and optionally provides a result.

```swift
fun add(a = 0, b = 0) {
    return a + b;
}
```

## Return With A Value

Place the return value on the same line as `return`.

```swift
fun square(n = 0) {
    return n * n;
}
```

The value can be any expression.

```swift
return [1, 2, 3];
return {"ok": true};
return condition ? left : right;
```

## Return Without A Value

If `return` is followed by a semicolon or newline, the function returns `nil`.

```swift
fun stop() {
    return;
}

fun also_stop() {
    return
}
```

## Early Return

Return is commonly used to exit early.

```swift
fun find_first_even(values = []) {
    for value in values {
        if value % 2 == 0 {
            return value;
        }
    }

    return nil;
}
```

## Constructors

Constructors cannot return an explicit value. In a constructor, `return` returns `this`.

```swift
class Point {
    constructor(x = 0, y = 0) {
        this.x = x;
        this.y = y;
        return;
    }
}
```

This is invalid:

```swift
class Point {
    constructor() {
        return 123;
    }
}
```

## Delimiters

`return` must be followed by a delimiter after its expression: a semicolon, newline, closing brace, or end of file.

```swift
return value
```

## Unreachable Code

Inside a braced block, code after `return` in the same block is unreachable and may be reported as an error.

```swift
fun example() {
    return 1;
    println("unreachable");
}
```
