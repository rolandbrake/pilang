# 5.2 While Loop

`while` repeats a body while a condition is truthy.

```pilang
let i = 0;

while i < 5 {
    println(i);
    i++;
}
```

## Conditions

The condition is an expression. Parentheses are optional.

```pilang
while i < 10 {
    i++;
}

while (i < 10) {
    i++;
}
```

The condition is checked before each iteration. If it is falsey the first time, the body never runs.

Falsey values include `false`, `nil`, numeric `0`, empty strings, empty lists, empty maps, empty tensors, modules with no exports, and ranges whose start and end are the same.

```pilang
let ready = false;

while ready {
    println("not printed");
}
```

## Braced Bodies

Use braces for multi-statement loop bodies.

```pilang
while count > 0 {
    println(count);
    count--;
}
```

Variables declared with `let` inside the block are local to that block iteration scope.

## Single-Statement Bodies

For one statement, braces are optional.

```pilang
while i < 5
    i++;
```

This is useful for compact loops, but braces are recommended for readability when the body has side effects.

## Infinite Loops

Use a truthy condition for an intentional infinite loop, then use `break` when a condition is met.

```pilang
fun next_line() {
    return nil;
}

while true {
    let line = next_line();
    if line == nil {
        break;
    }
    println(line);
}
```

## Continue In While Loops

`continue` skips the rest of the current iteration and jumps back to the condition.

```pilang
let i = 0;

while i < 10 {
    i++;
    if i % 2 == 0 {
        continue;
    }
    println(i);
}
```

## Common Pitfall

Make sure the loop body changes something that can make the condition false.

```pilang
let i = 0;

while i < 10 {
    // Without i++, this loop never ends.
    i++;
}
```
