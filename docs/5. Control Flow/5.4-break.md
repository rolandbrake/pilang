# 5.4 Break

`break` exits the nearest enclosing loop.

```swift
let values = [1, 2, 3, 4];
let target = 3;

for value in values {
    if value == target {
        break;
    }
}
```

It works in both `for` and `while` loops.

```swift
let i = 0;

while true {
    if i >= 10 {
        break;
    }
    i++;
}
```

## In For Loops

In a `for` loop, `break` also cleans up the active iterator before jumping out of the loop.

```swift
for item in [1, 2, 3, 4] {
    if item > 2 {
        break;
    }
    println(item);
}
```

This prints `1` and `2`, then exits the loop.

## Nested Loops

`break` exits only the innermost loop.

```swift
for row in 0..3 {
    for col in 0..3 {
        if col == 1 {
            break;
        }
        println(row + ", " + col);
    }
}
```

To exit multiple loop levels, use a flag or return from a function.

```swift
fun found(row = 0, col = 0) {
    return row == 1 && col == 1;
}

let done = false;

for row in 0..3 {
    for col in 0..3 {
        if found(row, col) {
            done = true;
            break;
        }
    }

    if done {
        break;
    }
}
```

## Placement Rules

`break` can only appear inside a loop. Using it outside a loop is a parser error.

```swift
// Invalid
break;
```

`break` must be followed by a statement delimiter: a semicolon, newline, closing brace, or end of file.

```swift
if stop {
    break
}
```

## Unreachable Code

Inside a braced block, code after `break` in the same block is unreachable and may be reported as an error.

```swift
while true {
    break;
    println("unreachable");
}
```
