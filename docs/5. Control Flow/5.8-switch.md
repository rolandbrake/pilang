# 5.8 Switch

`switch` checks a sequence of explicit condition cases and runs the first body
whose condition is truthy. The `_` case is the default path.

```pilang
switch exp {
    exp == 1:
        println(1)
    exp > 2 && exp < 4:
        println(2)
    exp in 1..10:
        println(3)
    exp in [1, 2, 3]:
        println(4)
    _:
        println(5)
}
```

Case conditions do not implicitly compare against the switch expression. Write
the condition you want directly.

```pilang
switch exp {
    exp in 1..10:
        println("inside the range")
    1..10:
        println("the range object itself is truthy")
}
```

Use a single statement after `:` for short cases. Use braces when a case body
has more than one statement.

```pilang
switch score {
    score >= 90: println("A")
    score >= 80: {
        println("B")
        passed = true
    }
    _: println("needs review")
}
```

There is no fallthrough. Once a case body runs, the switch statement ends.
