# 9.1 Grammar

This page gives a practical grammar overview. It is intentionally readable rather
than a byte-for-byte parser listing.

## Program

```ebnf
program       ::= declaration* EOF
declaration   ::= variableDecl
                | functionDecl
                | classDecl
                | statement
```

## Declarations

```ebnf
variableDecl  ::= ("let" | "const") variableItem ("," variableItem)* terminator?
variableItem  ::= identifier ("=" expression)?

functionDecl  ::= "fun" identifier "(" parameters? ")" block terminator?
parameters    ::= parameter ("," parameter)*
parameter     ::= identifier ("=" expression)?

classDecl     ::= "class" identifier (":" identifier)? "{" classMember* "}"
classMember   ::= identifier "(" parameters? ")" block
                | identifier "=" expression
```

Examples:

```pilang
let x = 10, y = 20
const answer = 42

fun add(a, b = 0) {
    return a + b
}

class Point {
    kind = "point"

    constructor(x, y) {
        this.x = x
        this.y = y
    }
}
```

## Statements

```ebnf
statement     ::= block
                | ifStmt
                | whileStmt
                | forStmt
                | breakStmt
                | continueStmt
                | returnStmt
                | importStmt
                | expressionStmt

block         ::= "{" declaration* "}"
breakStmt     ::= "break" terminator?
continueStmt  ::= "continue" terminator?
returnStmt    ::= "return" expression? terminator?
expressionStmt ::= expression terminator?
```

## Control Flow

```ebnf
ifStmt        ::= "if" expression blockOrStmt
                  ("elif" expression blockOrStmt)*
                  ("else" blockOrStmt)?

whileStmt     ::= "while" expression blockOrStmt
forStmt       ::= "for" "("? identifier "in" expression ")"? blockOrStmt

blockOrStmt   ::= block | statement
```

Conditions may be written with or without parentheses. Parentheses group part of
the expression, so logical operators may follow a grouped condition.

```pilang
if x > 0 {
    println(x)
}

while (running) {
    tick()
}

if (ready && configured) || override {
    start()
}

for item in values {
    println(item)
}
```

## Imports

```ebnf
importStmt    ::= "import" importPath importTail? terminator?
importPath    ::= identifier ("." identifier)*
importTail    ::= ":" identifier
                | ".*"
                | ".{" importBinding ("," importBinding)* "}"
importBinding ::= identifier (":" identifier)?
```

Examples:

```pilang
import math
import tensor:ten
import math.*
import math.{floor, ceil}
import tensor.{eye:identity, size}
import tensor.ones:make_ones
```

## Expressions

```ebnf
expression    ::= assignment

assignment    ::= conditional (assignOp assignment)?
assignOp      ::= "=" | "+=" | "-=" | "*=" | "/=" | "%="
                | "|=" | "^=" | "&="

conditional   ::= logicalOr ("?" expression ":" expression)?
logicalOr     ::= logicalAnd ("||" logicalAnd)*
logicalAnd    ::= membership ("&&" membership)*
membership    ::= range ("in" range)*
range         ::= bitOr (".." bitOr (":" bitOr)?)?
bitOr         ::= bitXor ("|" bitXor)*
bitXor        ::= bitAnd ("^" bitAnd)*
bitAnd        ::= shift ("&" shift)*
shift         ::= equality (("<<" | ">>" | ">>>") equality)*
equality      ::= comparison (("==" | "!=" | "is") comparison)*
comparison    ::= addition (("<" | ">" | "<=" | ">=") addition)*
addition      ::= dotProduct (("+" | "-") dotProduct)*
dotProduct    ::= multiplication (("@" | "*.") multiplication)*
multiplication ::= exponent (("*" | "/" | "%") exponent)*
exponent      ::= unary ("**" unary)*
unary         ::= ("+" | "-" | "!" | "~" | "#" | "typeof" | "++" | "--") unary
                | postfix
```

Assignment targets may be names, properties, indexes, or destructuring targets
where supported.

## Postfix Expressions

```ebnf
postfix       ::= primary postfixPart*
postfixPart   ::= "." identifier
                | "[" indexOrSlice "]"
                | "(" arguments? ")"
                | "++"
                | "--"

arguments     ::= argument ("," argument)*
argument      ::= expression
                | "..." expression
                | identifier "=" expression
```

Once a named argument appears in a call, later arguments must also be named.

## Primary Expressions

```ebnf
primary       ::= number
                | string
                | "true" | "false" | "nil" | "INF" | "NAN"
                | identifier
                | "super"
                | listLiteral
                | mapLiteral
                | setLiteral
                | tupleLiteral
                | functionLiteral
                | arrowFunction
                | "(" expression ")"

listLiteral   ::= "[" listItem ("," listItem)* ","? "]"
listItem      ::= "..." expression | expression
tupleLiteral  ::= "(" expression "," expression ("," expression)* ","? ")"
mapLiteral    ::= "{" mapEntry ("," mapEntry)* ","? "}"
mapEntry      ::= key ":" expression
                | identifier "(" parameters? ")" block
setLiteral    ::= "{" expression ("," expression)* ","? "}"
functionLiteral ::= "fun" "(" parameters? ")" block
arrowFunction ::= identifier "->" (expression | block)
                | "(" parameters? ")" "->" (expression | block)
```

An empty `{}` is an empty map/object literal. A non-empty `{ ... }` is parsed as
a map/object literal when it contains key-value entries, and as a set literal
otherwise.
