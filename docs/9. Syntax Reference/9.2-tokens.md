# 9.2 Tokens

Tokens are the smallest syntax units recognized by the scanner.

## Literals

| Token | Examples | Notes |
| --- | --- | --- |
| Number | `10`, `100_000`, `3.14`, `.5`, `1e6`, `0xFF`, `0b1010`, `0o77` | Decimal, exponent, hex, binary, and octal forms are recognized. `_` may separate decimal digits. |
| String | `"hello"`, `'hello'` | Both quote styles are accepted. |
| Identifier | `name`, `_hidden`, `value2` | Starts with a letter or `_`, then letters, digits, or `_`. |
| Boolean | `true`, `false` | Keyword literals. |
| Nil | `nil` | Absence of a value. |
| Infinity / NaN | `INF`, `NAN` | Numeric constants. |

## Delimiters

| Token | Meaning |
| --- | --- |
| `(` `)` | grouping, calls, parameters, tuples |
| `[` `]` | lists, indexing, slicing, tensor indexes |
| `{` `}` | blocks, maps, objects, sets, classes |
| `,` | item separator |
| `:` | map key separator, slice part, alias separator, class parent separator |
| `;` | optional statement terminator |
| `.` | member access or module path separator |

## Operators

| Token | Meaning |
| --- | --- |
| `=` | assignment |
| `+` `-` `*` `/` `%` | arithmetic |
| `**` | exponentiation |
| `@` `*.` | dot product operator |
| `++` `--` | increment and decrement |
| `+=` `-=` `*=` `/=` `%=` | compound arithmetic assignment |
| `&` `|` `^` `~` | bitwise operators |
| `&=` `|=` `^=` | compound bitwise assignment |
| `<<` `>>` `>>>` | shifts |
| `==` `!=` `<` `>` `<=` `>=` | comparison |
| `&&` `||` `!` | logical operators |
| `? :` | conditional expression |
| `..` | range |
| `...` | spread |
| `<-` | left-arrow assignment expression |
| `->` | arrow function |
| `#` | length/size unary operator |

Some compound tokens such as `**=`, `<<=`, `>>=`, `>>>=`, `&&=`, `||=`, and
`@=` are recognized by the scanner. Not every scanned compound token is accepted
as an assignment expression by the current parser; use the documented assignment
operators from the Operators chapter for portable code.

## Comments

Single-line comments start with `//`.

```pilang
// This is a comment.
let x = 10
```

Block comments use `/* ... */`.

```pilang
/*
This comment can span
multiple lines.
*/
let y = 20
```

Comments are removed before parsing and do not produce runtime values.
