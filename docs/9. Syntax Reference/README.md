# 9. Syntax Reference

This chapter is a compact reference for Pilang syntax. It summarizes the grammar,
tokens, keywords, naming rules, and statement separation rules used by the
parser.

For tutorial-style explanations, see the earlier chapters on language basics,
data types, operators, control flow, functions, objects, and modules.
