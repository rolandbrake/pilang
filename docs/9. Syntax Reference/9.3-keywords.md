# 9.3 Keywords

Keywords are reserved words. They cannot be used as ordinary identifiers.

## Control Flow

| Keyword | Use |
| --- | --- |
| `if` | starts a conditional branch |
| `elif` | adds another conditional branch |
| `else` | fallback branch |
| `while` | starts a while loop |
| `for` | starts a for-in loop |
| `in` | loop membership and membership operator |
| `break` | exits a loop |
| `continue` | jumps to the next loop iteration |
| `return` | exits a function |

## Declarations and Objects

| Keyword | Use |
| --- | --- |
| `let` | declares local/module variables |
| `fun` | declares or creates a function |
| `class` | declares a class/prototype |
| `super` | accesses a parent prototype inside methods |
| `import` | imports a module |

## Values and Type Operators

| Keyword | Use |
| --- | --- |
| `true` | boolean true |
| `false` | boolean false |
| `nil` | no value |
| `INF` | infinity |
| `NAN` | not-a-number |
| `is` | identity/type-style comparison |
| `typeof` | unary type operator |

## Other Reserved Words

| Keyword | Status |
| --- | --- |
| `debug` | reserved for debug statements |
| `goto` | reserved token; avoid using it |

Because these names are reserved, use alternatives such as `kind`, `type_name`,
`is_valid`, or `debug_mode` for variables and fields.
