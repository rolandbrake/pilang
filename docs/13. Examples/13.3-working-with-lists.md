# 13.3 Working with Lists

Lists are ordered, mutable collections.

```swift
numbers = [3, 1, 4, 1, 5]

println(numbers[0])  // 3
println(numbers[-1]) // 5
println(numbers[7])  // wraps around
```

Indexes wrap around the list length. Large indexes are rounded back into the valid range.

## Iterating

```swift
numbers = [10, 20, 30]

for n in numbers {
    println(n)
}
```

## Summing a list

```swift
fn sum(values) {
    let total = 0

    for value in values {
        total += value
    }

    return total
}

println(sum([1, 2, 3, 4])) // 10
```

Use `let` for locals inside functions. Without `let`, assignment inside a local scope creates or writes a module-global variable.

## Adding items

The `+` operator can append an item to a list.

```swift
items = []
items = items + "first"
items = items + "second"

println(items) // ["first", "second"]
```

The `col` module also provides collection helpers.

```swift
import col:c

items = [1, 2]
c.append(items, 3, 4)

println(items) // [1, 2, 3, 4]
```

## Slicing

```swift
letters = ["a", "b", "c", "d", "e"]

println(letters[1:4])  // ["b", "c", "d"]
println(letters[0:5:2]) // ["a", "c", "e"]
```

## Filtering manually

```swift
fn only_even(values) {
    let result = []

    for value in values {
        if value % 2 == 0 {
            result = result + value
        }
    }

    return result
}

println(only_even([1, 2, 3, 4, 5, 6])) // [2, 4, 6]
```

## Mapping manually

```swift
fn square_all(values) {
    let result = []

    for value in values {
        result = result + (value * value)
    }

    return result
}

println(square_all([1, 2, 3, 4])) // [1, 4, 9, 16]
```

## Sorting and reversing

```swift
import col:c

values = [3, 1, 4, 2]

println(c.sort(values))
println(c.reverse(values))
```

## Lists of maps

```swift
users = [
    {"name": "Mira", "active": true},
    {"name": "Sam", "active": false},
    {"name": "Noor", "active": true}
]

for user in users {
    if user["active"] {
        println(user["name"])
    }
}
```

## What this example uses

- indexing and wraparound
- slicing
- loops
- `let` locals
- list appending
- maps inside lists
- `col` module helpers
