# 13.4 Classes and Objects

Pilang supports primitive maps and class declarations. Use maps for flexible
data records. Use classes when you want named types, constructors, methods, and
inheritance.

## A class

```swift
class Point {
    constructor(x = 0, y = 0) {
        this.x = x
        this.y = y
    }

    move(dx, dy) {
        this.x += dx
        this.y += dy
        return this
    }

    length() {
        return (this.x ** 2 + this.y ** 2) ** 0.5
    }

    format() {
        return "Point(" + this.x + ", " + this.y + ")"
    }
}

p = Point(3, 4)

println(p.format()) // Point(3, 4)
println(p.length()) // 5

p.move(10, -2)
println(p.format()) // Point(13, 2)
```

## Inheritance

```swift
class Animal {
    constructor(name) {
        this.name = name
    }

    speak() {
        return this.name + " makes a sound"
    }
}

class Dog : Animal {
    constructor(name, breed) {
        super(name)
        this.breed = breed
    }

    speak() {
        return this.name + " barks"
    }

    describe() {
        return this.name + " is a " + this.breed
    }
}

dog = Dog("Luna", "shepherd")

println(dog.speak())
println(dog.describe())
```

## A map record

```swift
let counter = {
    "value": 0,

    "label": "main counter"
}

println(counter["value"]) // 0
counter["value"] = 2
println(counter["value"]) // 2
```

Maps are flexible. You can add fields freely:

```swift
counter["label"] = "main counter"
println(counter["label"])
```

## When to use each form

Use classes when:

- the value has a clear type name
- you want constructor syntax
- you want inheritance
- several instances should share methods

Use maps when:

- you need a small record
- fields are dynamic
- the value is mostly data
- you want bracket-key access

## What this example uses

- classes
- constructors
- methods
- `this`
- inheritance
- `super`
- primitive map records
