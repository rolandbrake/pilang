# 13.5 Tensor Operations

The `tensor` module provides multidimensional numeric arrays and numeric operations.

```pilang
import tensor:t
```

## Creating tensors

```pilang
import tensor:t

zeros = t.zeros(2, 3)
ones = t.ones(2, 3)
identity = t.eye(3)
matrix = t.from([[1, 2], [3, 4]])

println(zeros)
println(ones)
println(identity)
println(matrix)
```

## Shape and size

```pilang
import tensor:t

m = t.ones(2, 3)

println(t.shape(m)) // [2, 3]
println(t.ndim(m))  // 2
println(t.size(m))  // 6
```

## Elementwise operations

```pilang
import tensor:t

a = t.from([1, 2, 3])
b = t.from([10, 20, 30])

println(t.add(a, b))
println(t.sub(b, a))
println(t.mult(a, 5))
println(t.div(b, 10))
```

## Applying a function

```pilang
import tensor:t

values = t.from([1, 2, 3, 4])
squares = t.apply(values, x -> x * x)

println(squares)
```

## Matrix multiplication

```pilang
import tensor:t

a = t.from([
    [1, 2],
    [3, 4]
])

b = t.from([
    [10, 20],
    [30, 40]
])

println(t.matmult(a, b))
```

## Statistics

```pilang
import tensor:t

values = t.from([2, 4, 6, 8])

println(t.sum(values))    // 20
println(t.mean(values))   // 5
println(t.min(values))    // 2
println(t.max(values))    // 8
println(t.prod(values))   // 384
println(t.std(values))
```

## Linear algebra

```pilang
import tensor:t

m = t.from([
    [1, 2],
    [3, 4]
])

println(t.det(m))
println(t.trace(m))
println(t.transpose(m))
```

## Solving a system

```pilang
import tensor:t

// 2x = 8
// 4y = 20
a = t.from([
    [2, 0],
    [0, 4]
])

b = t.from([8, 20])

solution = t.solve(a, b)
println(solution)
```

## What this example uses

- tensor creation
- shape helpers
- elementwise math
- function application with `->`
- matrix multiplication
- statistics
- linear algebra helpers
