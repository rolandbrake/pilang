# 13.1 Hello World

This is the smallest useful Pilang program.

```swift
println("Hello, Pilang!")
```

Save it as `hello.pi` and run:

```text
pi run hello.pi
```

## With variables

```swift
name = "Pilang"
println("Hello, " + name + "!")
```

Top-level variables belong to the module.

## With a function

```swift
fun greet(name) {
    return "Hello, " + name + "!"
}

println(greet("Pilang"))
println(greet("docs"))
```

## With command-line arguments

The `sys` module can be used for program information and command-line arguments.

```swift
import sys:s

println("Program started")
println("Arguments:")

for arg in s.argv() {
    println(arg)
}
```

Run it with extra arguments:

```text
pi run hello.pi first second
```

## With a module import

```swift
import time:t

now = t.now()
println("Hello from Pilang")
println(t.iso(now))
```

This example imports the `time` module with the alias `t`, gets the current time, and formats it as an ISO string.

## What this example uses

- strings
- variables
- functions
- module imports
- `for ... in`
- command-line execution
