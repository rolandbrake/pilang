# 14.3 Operator Table

This table summarizes Pilang operators. See the Operators chapter for detailed behavior and overload rules.

## Precedence

From highest to lowest:

| Level | Operators | Meaning |
| --- | --- | --- |
| 1 | `.`, `[]`, `()` | member access, indexing, slicing, calls |
| 2 | unary `+`, unary `-`, `!`, `~`, `#`, `++`, `--`, `typeof` | unary operations |
| 3 | `**` | exponentiation |
| 4 | `*`, `/`, `%` | multiplication, division, modulo |
| 5 | `@`, `*.` | dot product |
| 6 | `+`, `-` | addition, subtraction, iterable append in special cases |
| 7 | `==`, `!=`, `<`, `>`, `<=`, `>=`, `is` | equality, comparison, prototype-chain test |
| 8 | `<<`, `>>`, `>>>` | shifts |
| 9 | `&` | bitwise AND |
| 10 | `^` | bitwise XOR |
| 11 | `|` | bitwise OR |
| 12 | `..`, `..:step` | ranges |
| 13 | `in` | membership |
| 14 | `&&` | logical AND |
| 15 | `||` | logical OR |
| 16 | `? :` | conditional expression |
| 17 | `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `|=`, `^=`, `&=`, `<-` | assignment forms |

## Arithmetic

| Operator | Example | Meaning |
| --- | --- | --- |
| `+` | `a + b` | addition, string/list append in special cases |
| `-` | `a - b` | subtraction |
| `*` | `a * b` | multiplication, iterable repetition when repeated by a number |
| `/` | `a / b` | division |
| `%` | `a % b` | remainder |
| `**` | `a ** b` | exponentiation |
| `@`, `*.` | `a @ b` | dot product style operation |

## Comparison And Logic

| Operator | Example | Meaning |
| --- | --- | --- |
| `==` | `a == b` | equality |
| `!=` | `a != b` | inequality |
| `<`, `<=` | `a < b` | less-than comparisons |
| `>`, `>=` | `a > b` | greater-than comparisons |
| `is` | `a is Prototype` | prototype-chain test for map/object values |
| `in` | `item in collection` | membership |
| `&&` | `a && b` | logical AND |
| `||` | `a || b` | logical OR |
| `!` | `!value` | logical NOT |

## Bitwise

| Operator | Example | Meaning |
| --- | --- | --- |
| `&` | `a & b` | bitwise AND |
| `|` | `a | b` | bitwise OR |
| `^` | `a ^ b` | bitwise XOR |
| `~` | `~a` | bitwise NOT |
| `<<` | `a << b` | left shift |
| `>>` | `a >> b` | right shift |
| `>>>` | `a >>> b` | unsigned right shift |

## Assignment

| Operator | Example | Meaning |
| --- | --- | --- |
| `=` | `x = value` | assignment |
| `+=` | `x += value` | add then assign |
| `-=` | `x -= value` | subtract then assign |
| `*=` | `x *= value` | multiply then assign |
| `/=` | `x /= value` | divide then assign |
| `%=` | `x %= value` | modulo then assign |
| `&=` | `x &= value` | bitwise AND then assign |
| `|=` | `x |= value` | bitwise OR then assign |
| `^=` | `x ^= value` | bitwise XOR then assign |
| `<-` | `target <- value` | left-arrow assignment expression |

## Other Operators

| Operator | Example | Meaning |
| --- | --- | --- |
| `.` | `object.name` | member access |
| `[]` | `list[0]` | indexing |
| `[:]` | `list[1:3]` | slicing |
| `()` | `fn_value()` | call |
| `..` | `1..10` | range |
| `...` | `fn(...args)` | spread |
| `->` | `x -> x * 2` | arrow function |
| `? :` | `ok ? a : b` | conditional expression |
| `#` | `#items` | length/size |
| `++`, `--` | `i++`, `--i` | increment and decrement |

## Notes

Use parentheses when mixing operator families:

```swift
value = (a + b) * (c - d)
```

Indexes wrap for sequences. If the index is larger than the iterable length, Pilang rounds it back into range.
