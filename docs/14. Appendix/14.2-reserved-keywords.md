# 14.2 Reserved Keywords

Reserved keywords cannot be used as normal identifiers.

## Keyword List

| Keyword | Use |
| --- | --- |
| `false` | boolean false |
| `true` | boolean true |
| `for` | starts a for-in loop |
| `in` | loop membership and membership operator |
| `while` | starts a while loop |
| `fun` | declares or creates a function |
| `let` | declares a variable |
| `const` | declares a binding that cannot be rebound |
| `INF` | positive infinity constant |
| `NAN` | not-a-number constant |
| `break` | exits a loop |
| `continue` | continues to the next loop iteration |
| `goto` | reserved token; avoid using it |
| `if` | starts a conditional |
| `else` | fallback branch |
| `elif` | additional conditional branch |
| `switch` | starts a condition switch |
| `nil` | absence of a value |
| `is` | identity/type-style comparison |
| `return` | exits a function |
| `class` | declares a class/prototype |
| `super` | accesses a parent prototype |
| `typeof` | unary type operator |
| `debug` | debug instruction |
| `import` | imports modules or symbols |
| `match` | reserved for future pattern matching syntax |

## Examples

Invalid:

```swift
let class = "User"
let return = 10
```

Valid alternatives:

```swift
let class_name = "User"
let return_value = 10
```

## Related Names

Some important words are not scanner-reserved keywords, but they still have special meaning in common contexts.

| Name | Meaning |
| --- | --- |
| `this` | current receiver inside constructors and methods |
| `constructor` | constructor method name for classes and object prototypes |
| `args` | positional argument list available to functions that read it |
| `kw_args` | named argument map available to functions that read it |

Avoid reusing these names for unrelated purposes inside functions and methods.
