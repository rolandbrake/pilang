# 14.4 Built-in Function Index

This page lists the global built-in constants and functions. Built-in modules are documented in [8.4 Built-in Modules](../8.%20Modules/8.4%20Built-in%20Modules/README.md).

## Constants

| Name | Meaning |
| --- | --- |
| `INF` | positive infinity |
| `NAN` | not-a-number |

| --- | --- |

## Native Receiver Methods

Some receiver-first built-ins are also available with dot syntax. The receiver
is passed as the first argument to the same native function.

```swift
trim("  text  ");
"  text  ".trim();

append(items, value);
items.append(value);
```

| Type | Methods |
| --- | --- |
| string | `trim`, `upper`, `lower`, `append`, `push`, `pop`, `peek`, `len`, `length`, `contains`, `includes`, `index`, `indexOf`, `count`, `repeat`, `copy`, `reverse`, `split` |
| list | `append`, `push`, `pop`, `peek`, `insert`, `remove`, `len`, `length`, `contains`, `includes`, `index`, `indexOf`, `count`, `concat`, `repeat`, `copy`, `join`, `reverse`, `flat`, `sort`, `shuffle`, `map` |
| tuple | `len`, `length`, `contains`, `includes`, `index`, `indexOf`, `count`, `concat`, `repeat`, `join` |
| set | `add`, `clear`, `len`, `length`, `contains`, `includes`, `union`, `intersection`, `difference`, `symmetric_diff`, `symmetricDiff`, `issubset`, `isSubset`, `issuperset`, `isSuperset`, `isdisjoint`, `isDisjoint` |
