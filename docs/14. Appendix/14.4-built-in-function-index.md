# 14.4 Built-in Function Index

This page lists the global built-in constants and functions. Built-in modules are documented in [8.4 Built-in Modules](../8.%20Modules/8.4%20Built-in%20Modules/README.md).

## Constants

| Name | Meaning |
| --- | --- |
| `INF` | positive infinity |
| `NAN` | not-a-number |

## I/O

| Function | Summary |
| --- | --- |
| `print(value, ...)` | prints values without automatically adding a newline |
| `println(value, ...)` | prints values and adds a newline |
| `printf(format, ...)` | prints formatted text |
| `log(value, flag = nil)` | writes a log-style message |
| `input(prompt)` | reads input after showing a prompt |

## Time

| Function | Summary |
| --- | --- |
| `sleep(ms)` | pauses for a number of milliseconds |
| `time()` | returns a time value |

## Math

| Function | Summary |
| --- | --- |
| `abs(value)` | absolute value |
| `min(a, b, ...)` | minimum value |
| `max(a, b, ...)` | maximum value |
| `pow(base, exponent)` | exponentiation |
| `round(value)` | rounded number |
| `seed(value)` | seeds random generation |
| `rand()` | random number |
| `rand_n(n)` | random number with an upper bound or range behavior |

## Strings

| Function | Summary |
| --- | --- |
| `char(code)` | character from numeric code |
| `ord(text)` | numeric code of the first character |
| `trim(text)` | returns text without surrounding whitespace |
| `upper(text)` | uppercase text |
| `lower(text)` | lowercase text |

## System

| Function | Summary |
| --- | --- |
| `error(message)` | raises a runtime error |
| `assert(condition, message)` | raises an error if condition is falsey |
| `zen()` | prints or returns Pilang's zen message |

## Type

| Function | Summary |
| --- | --- |
| `type(value)` | returns the value type name |
| `is_num(value)` | checks for numeric value |
| `is_str(value)` | checks for string value |
| `is_bool(value)` | checks for boolean value |
| `is_list(value)` | checks for list value |
| `is_map(value)` | checks for map value |
| `as_num(value)` | converts to number when possible |
| `as_string(value)` | converts to string |
| `as_bool(value)` | converts to boolean using truthiness |

## Collections

| Function | Summary |
| --- | --- |
| `push(collection, value, ...)` | appends values to a list or string |
| `pop(collection)` | removes and returns the last item |
| `peek(collection)` | returns the last item without removing it |
| `empty(collection)` | checks whether a collection is empty |
| `insert(collection, index, value)` | inserts a value |
| `remove(collection, indexOrKey)` | removes an item |
| `slice(start, end, step = 1)` | creates a slice descriptor |
| `len(value)` | returns collection length or tensor size |
| `tuple(value, ...)` | creates a tuple |
| `contains(collection, value)` | membership check |
| `index(collection, value)` | index of a value |
| `count(collection, value)` | count occurrences |
| `concat(a, b)` | concatenates compatible collections |
| `repeat(collection, count)` | repeats a list, tuple, or string |
| `range(end)` | creates a range |
| `range(start, end)` | creates a range |
| `range(start, end, step)` | creates a stepped range |
| `copy(value)` | copies supported values |

## Sets

| Function | Summary |
| --- | --- |
| `set(iterable = nil)` | creates a set |
| `union(a, b, ...)` | set union |
| `intersection(a, b, ...)` | set intersection |
| `difference(a, b)` | set difference |
| `symmetric_diff(a, b)` | symmetric set difference |
| `issubset(a, b)` | subset check |
| `issuperset(a, b)` | superset check |
| `isdisjoint(a, b)` | disjointness check |

## Functional

| Function | Summary |
| --- | --- |
| `map(list, fn)` | transforms every list item |
| `filter(list, predicate)` | keeps items whose predicate result is truthy |
| `reduce(list, fn, initial = nil)` | folds a list into one value |
| `find(collection, predicate)` | returns the first matching index or `-1` |

## Objects And Maps

| Function | Summary |
| --- | --- |
| `clone(map)` | clones a map/object |
| `values(map)` | returns map values |
| `keys(map)` | returns map keys |
