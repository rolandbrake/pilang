# 14.6 FAQ

## What is Pilang?

Pilang is a dynamic programming language with functions, classes, maps, modules, collections, tensors, graphics, and a stack-based virtual machine.

## How do I run a Pilang file?

```text
pi run main.pi
```

The shorthand form is also supported:

```text
pi main.pi
```

## Are semicolons required?

No. Semicolons are optional. A newline can end a statement when the parser can determine that the statement is complete.

```swift
let x = 10
let y = 20
println(x + y)
```

## What arrow syntax does Pilang use?

Pilang uses `->`.

```swift
double = n -> n * 2
sum = (a, b) -> a + b
```

It uses `->` for function arrows. The separate `=>` operator is the pipeline
operator.

## What is the difference between `fun` and `fun`?

The parser keyword is `fun`. The documentation examples also use `fun` as the common function declaration style already used throughout the docs and examples. Use the form supported by your current Pilang build.

```swift
fun add(a, b) {
    return a + b
}
```

## When should I use `let`?

Use `let` when declaring a variable, especially inside local scopes.

```swift
fun total(values) {
    let result = 0

    for value in values {
        result += value
    }

    return result
}
```

Inside a local scope, assignment without a declaration can create or write a module-global variable.

## Why did my local variable become global?

Pilang hoists variables assigned inside local scopes without a declaration to the module global scope.

```swift
fun demo() {
    leaked = 10
}

demo()
println(leaked) // module global
```

Use `let` for local variables:

```swift
fun demo() {
    let local_value = 10
}
```

## How does indexing work?

Sequence indexes wrap around. If an index is larger than the length, Pilang rounds it back into the valid range.

```swift
values = ["a", "b", "c"]

println(values[3]) // "a"
println(values[4]) // "b"
```

Negative indexes are also supported for sequences.

## Are lists and strings copied by `map` or `filter`?

The returned list is new, but contained objects are not deep-cloned. If the callback mutates an object item, that object is changed.

```swift
users = [{"score": 1}]

map(users, fun (user) {
    user["score"] += 1
    return user
})

println(users[0]["score"]) // 2
```

## Does `reduce` need an initial value?

Use an initial value when the list might be empty or when the accumulator type is different from the item type.

```swift
total = reduce([], fun (acc, n) {
    return acc + n
}, 0)
```

Reducing an empty list without an initial value is an error.

## What is the difference between maps and classes?

Maps are flexible object-like data containers. Classes are structured prototypes with class syntax, constructors, methods, inheritance, and stricter defaults.

Use maps for simple records. Use classes when you want a named reusable type.

## How do I make a module member private?

Use a leading underscore for top-level module names that should not be imported as public symbols.

```swift
_helper = fun () {
    return "internal"
}
```

For classes and objects, leading `_` is a convention for private members.

## Which names should modules use?

Use one lowercase word for module aliases.

```swift
import tensor:t
import string:s
import fs:f
```

## How do I work with files?

Use the `fs` module and close file handles when finished.

```swift
import fs:f

file = f.open("notes.txt", "w")
f.write(file, "hello\n")
f.close(file)
```

## When should I use tensors instead of lists?

Use tensors for numeric arrays, matrix-style data, and multidimensional operations. Use lists for general-purpose collections.

## How does garbage collection work?

Pilang uses a mark-and-sweep garbage collector. Reachable objects are marked from roots such as the stack, globals, call frames, modules, closures, and iterators. Unreachable objects are reclaimed.

## Is there a package manager?

The current system is module-based. A full package manager with manifests, version solving, and lockfiles is future tooling around the module system.
