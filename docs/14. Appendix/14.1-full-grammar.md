# 14.1 Full Grammar

This grammar is a practical reference for Pilang source syntax. It is written in readable EBNF-style notation rather than as a byte-for-byte copy of the parser.

## Notation

| Form | Meaning |
| --- | --- |
| `a b` | `a` followed by `b` |
| `a \| b` | either `a` or `b` |
| `a?` | optional `a` |
| `a*` | zero or more `a` |
| `a+` | one or more `a` |
| `"text"` | literal token |

## Program

```ebnf
program         ::= declaration* EOF
declaration     ::= variableDecl
                  | functionDecl
                  | classDecl
                  | statement
terminator      ::= ";" | newline
```

Semicolons are optional. A newline can end a statement when the parser has enough information to complete it.

## Declarations

```ebnf
variableDecl    ::= ("let" | "const") variableItem ("," variableItem)* terminator?
variableItem    ::= identifier ("=" expression)?

functionDecl    ::= "fun" identifier "(" parameters? ")" block terminator?
parameters      ::= parameter ("," parameter)* ","?
parameter       ::= identifier ("=" expression)?

classDecl       ::= "class" identifier (":" identifier)? "{" classMember* "}"
classMember     ::= identifier "(" parameters? ")" block
                  | identifier "=" expression terminator?
```

## Statements

```ebnf
statement       ::= block
                  | ifStmt
                  | switchStmt
                  | whileStmt
                  | forStmt
                  | breakStmt
                  | continueStmt
                  | returnStmt
                  | importStmt
                  | debugStmt
                  | expressionStmt

block           ::= "{" declaration* "}"
breakStmt       ::= "break" terminator?
continueStmt    ::= "continue" terminator?
returnStmt      ::= "return" expression? terminator?
debugStmt       ::= "debug" terminator?
expressionStmt  ::= expression terminator?
```

## Control Flow

```ebnf
ifStmt          ::= "if" condition blockOrStmt
                    ("elif" condition blockOrStmt)*
                    ("else" blockOrStmt)?

switchStmt      ::= "switch" expression "{" switchCase+ "}"
switchCase      ::= (expression | "_") ":" blockOrStmt

whileStmt       ::= "while" condition blockOrStmt
forStmt         ::= "for" "("? identifier "in" expression ")"? blockOrStmt

condition       ::= "(" expression ")" | expression
blockOrStmt     ::= block | statement
```

## Imports

```ebnf
importStmt      ::= "import" importItem ("," importItem)* terminator?
importItem      ::= importPath importAlias? importTail?
importPath      ::= identifier ("." identifier)*
importAlias     ::= ":" identifier
importTail      ::= ".*"
                  | ".{" importBinding ("," importBinding)* ","? "}"
importBinding   ::= identifier (":" identifier)?
```

Examples:

```pilang
import math
import math, random
import tensor:t
import math.*
import math.{floor, ceil}
import math:mt.{cos, sin}
import tensor.{eye:identity, size}
import tensor.ones:make_ones
```

## Expressions

```ebnf
expression      ::= assignment

assignment      ::= pipeline (assignOp assignment)?
assignOp        ::= "=" | "+=" | "-=" | "*=" | "/=" | "%="
                  | "|=" | "^=" | "&="

pipeline        ::= conditional ("=>" pipelineStage)*
pipelineStage   ::= postfix

conditional     ::= logicalOr ("?" expression ":" expression)?
logicalOr       ::= logicalAnd ("||" logicalAnd)*
logicalAnd      ::= membership ("&&" membership)*
membership      ::= range ("in" range)*
range           ::= bitOr (".." bitOr (":" bitOr)?)?
bitOr           ::= bitXor ("|" bitXor)*
bitXor          ::= bitAnd ("^" bitAnd)*
bitAnd          ::= shift ("&" shift)*
shift           ::= equality (("<<" | ">>" | ">>>") equality)*
equality        ::= comparison (("==" | "!=" | "is") comparison)*
comparison      ::= addition (("<" | ">" | "<=" | ">=") addition)*
addition        ::= dotProduct (("+" | "-") dotProduct)*
dotProduct      ::= multiplication (("@" | "*.") multiplication)*
multiplication  ::= exponent (("*" | "/" | "%") exponent)*
exponent        ::= unary ("**" unary)*
unary           ::= ("+" | "-" | "!" | "~" | "#" | "typeof" | "++" | "--") unary
                  | postfix
```

## Postfix

```ebnf
postfix         ::= primary postfixPart*
postfixPart     ::= "." identifier
                  | "[" indexOrSlice "]"
                  | "(" arguments? ")"
                  | "++"
                  | "--"

indexOrSlice    ::= expression
                  | expression? ":" expression? (":" expression?)?

arguments       ::= argument ("," argument)* ","?
argument        ::= expression
                  | "..." expression
                  | identifier "=" expression
```

Once a named argument appears in a call, later arguments should also be named.

## Primary Values

```ebnf
primary         ::= number
                  | string
                  | "true"
                  | "false"
                  | "nil"
                  | "INF"
                  | "NAN"
                  | identifier
                  | "super"
                  | listLiteral
                  | mapLiteral
                  | setLiteral
                  | tupleLiteral
                  | functionLiteral
                  | arrowFunction
                  | "(" expression ")"
```

## Literals

```ebnf
listLiteral     ::= "[" listItem? ("," listItem)* ","? "]"
listItem        ::= expression | "..." expression

tupleLiteral    ::= "(" ")"
                  | "(" expression "," ")"
                  | "(" expression "," expression ("," expression)* ","? ")"

mapLiteral      ::= "{" mapEntry? ("," mapEntry)* ","? "}"
mapEntry        ::= key ":" expression
                  | identifier "(" parameters? ")" block
key             ::= string | number | identifier | expression

setLiteral      ::= "{" expression ("," expression)* ","? "}"
```

An empty `{}` is a map/object literal. A non-empty `{ ... }` is parsed as a map/object literal when it contains key-value entries or method entries, and as a set literal otherwise.

## Functions

```ebnf
functionLiteral ::= "fun" "(" parameters? ")" block

arrowFunction   ::= identifier "->" arrowBody
                  | "(" parameters? ")" "->" arrowBody
arrowBody       ::= expression | block
```

Examples:

```pilang
fn add(a, b) {
    return a + b
}

double = n -> n * 2
sum = (a, b) -> a + b
```

## Comments

```ebnf
lineComment     ::= "//" charactersUntilNewline
blockComment    ::= "/*" charactersUntilClosingMarker "*/"
```

Comments are ignored by the parser.
