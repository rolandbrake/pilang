# 14.5 Changelog

This changelog records documentation milestones. Runtime release notes should be kept with the project release process.

## Current Documentation Draft

### Recently documented runtime features

- Added structural equality for lists, including nested lists.
- Added scalar broadcasting and elementwise power for tensor arithmetic.
- Added scalar iteration for one-dimensional tensors and row iteration for
  multidimensional tensors.
- Added compiler optimizations for local-variable access, constant folding,
  and compile-time dead-code elimination.

- Reorganized documentation into numbered chapters.
- Added Introduction pages.
- Added Language Basics, including local scope behavior and optional semicolons.
- Added Data Types, including tuples, sets, tensors, and bounded sequence indexing.
- Added Operators, including special iterable behavior, spread, `is`, `in`, left-arrow assignment, and operator overloading hooks.
- Added Control Flow, including falsey non-boolean values.
- Added Functions, including named arguments, `args`, `kw_args`, and arity.
- Updated Objects and Classes to document primitive maps separately from class values and instances.
- Added Modules and detailed built-in module pages.
- Added Syntax Reference, including grammar, tokens, keywords, naming conventions, and newline behavior.
- Added Memory Management, covering garbage collection, object lifetime, closures, and references.
- Added Functional Programming, including `map`, `filter`, `reduce`, composition, and iterator-style helpers.
- Added Advanced Topics, including VM architecture, bytecode, embedding, performance, and packaging guidance.
- Added Examples for common programming tasks.
- Added Appendix references, FAQ, and acknowledgements.

## Documentation Notes

- Arrow functions use `->`.
- Semicolons are optional.
- Top-level names beginning with `_` are private in module import/export behavior.
- Function and module examples prefer short lowercase aliases.
- Examples avoid relying on unstable ordering for sets and maps.

- Add package manager details when package metadata and dependency tooling exist.
