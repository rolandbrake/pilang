# 1.1 What is Pilang?

Pilang is a lightweight, embeddable, general-purpose programming language written in C.

It is designed as a practical scripting language with a bytecode-style VM, garbage collection, first-class functions, objects, modules, and a standard set of built-in libraries. Pilang source files usually use the `.pi` extension and are executed by the `pilang.exe` interpreter.

Pilang aims to be small enough to embed and understand, but expressive enough for real programs: command-line scripts, data processing, algorithms, filesystem work, graphics experiments, and numerical or tensor-based code.

## Design Goals

- Keep the runtime compact and portable.
- Make common scripting tasks direct and readable.
- Provide useful built-in modules for math, strings, files, system access, time, collections, tensors, drawing, and plotting.
- Support modern language features such as closures, maps, classes, operator hooks, and modules.
- Remain easy to build, inspect, and extend from C.

## Example

```pilang
println("Hello from Pilang!");
```
