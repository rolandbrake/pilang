# 1.5 REPL

The REPL (Read-Eval-Print Loop) is an interactive Pilang shell that allows you to execute code line-by-line without creating a source file.

REPL mode is started automatically when Pilang is launched without any command-line arguments:

```powershell
.\pilang.exe
```

Example startup:

```text
Pilang v0.0.3 (type 'exit' or press ^C to quit)

>>> 
```

## Features

The REPL maintains a persistent execution environment between commands. Variables, functions, classes, and imported modules remain available until the session ends.

```pilang
>>> a = 3
>>> a
3

>>> a + 3
6
```

Multi-line input is supported using a trailing backslash (`\`):

```pilang
>>> numbers = [
...     1, 2, 3, \
...     4, 5
... ]
```

## Built-in Commands

| Command | Description               |
| ------- | ------------------------- |
| `help`  | Display REPL help         |
| `clear` | Clear the terminal screen |
| `exit`  | Exit the REPL             |
| `quit`  | Exit the REPL             |

## Example Session

```pilang
>>> 1 + 2
3

>>> name = "Pilang"

>>> name
"Pilang"

>>> fun square(x) {
...     return x * x
... }

>>> square(5)
25
```

## Use Cases

The REPL is useful for:

* Experimenting with language features.
* Testing expressions and algorithms.
* Debugging small snippets of code.
* Learning the language interactively.
* Prototyping ideas before moving them into `.pi` files.

For larger programs, use source files and execute them with:

```powershell
.\pilang.exe run program.pi
```
