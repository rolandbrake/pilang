# 1.5 REPL

REPL means "read-eval-print loop": an interactive mode where you type an expression or statement and immediately see the result.

## Current Status

Pilang has internal parser/compiler support for `MODE_REPL`, and the browser/WebAssembly path uses REPL-style execution for submitted source snippets.

The current native command-line executable does not expose a separate `repl` command. Running `pi.exe` without arguments prints command help instead of starting an interactive shell.

Use files for native command-line work:

```powershell
.\pi.exe run test.pi
```

Use the browser/WebAssembly build when working with an interactive editor or page that sends source snippets to the runtime.

## REPL Behavior

In REPL mode, Pilang is intended to parse and evaluate one expression statement at a time. This makes it useful for quick experiments, checking syntax, and trying small pieces of code before placing them in a `.pi` file.

## Example

```pilang
1 + 2
```
