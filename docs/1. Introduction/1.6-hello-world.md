# 1.6 Hello World

The smallest useful Pilang program prints a line of text.

## Program

Create a file named `hello.pi`:

```pilang
println("Hello, world!");
```

Run it from the repository root:

```powershell
.\pilang.exe run hello.pi
```

You can also use the shorthand form:

```powershell
.\pilang.exe hello.pi
```

## What Happens

`println` writes its arguments to standard output and adds a newline. The string literal `"Hello, world!"` is the text being printed.

The native runner also prints an execution-time line after the program finishes.

## Another Example

```pilang
name = "Pilang";
println("Hello from " + name + "!");
```
