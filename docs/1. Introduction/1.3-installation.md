# 1.3 Installation

This repository currently includes a Windows executable named `pi.exe` at the project root. If you already have the repository, you can run Pilang scripts from that directory without a separate installer.

## Requirements

For the native Windows build in this repository:

- `pi.exe`
- SDL runtime DLLs beside the executable, including `SDL2.dll`, `SDL2_image.dll`, `SDL2_mixer.dll`, and `SDL2_ttf.dll`

For rebuilding from source on Windows, the VS Code task configuration uses:

- MinGW GCC at `C:\MinGW64\bin\gcc.exe`
- SDL2, SDL2_image, SDL2_mixer, and SDL2_ttf development libraries

## Using The Included Executable

Open a terminal in the repository root and run:

```powershell
.\pi.exe help
```

You should see the Pilang command help.

## Building From Source

The repository includes VS Code build tasks:

- `build-debug`
- `build-release`
- `build-emscripten`

The native tasks compile the C sources and built-in modules into the `pi` executable target. The Emscripten task builds the browser/WebAssembly version.

If you are not using VS Code, mirror the source list and linker options in `.vscode/tasks.json`.

## Example

```powershell
.\pi.exe --version
```
