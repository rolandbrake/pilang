# 1.3 Installation

Most people should use a Pilang release rather than build from source. A release
contains a ready-to-run `pilang` executable and does not require a compiler or
SDL development libraries.

## Build from source

Windows source builds use the checked-in static build kit in `deps/`. They do
not download or compile SDL dependencies.

### Windows

Install MSYS2 with its UCRT64 GCC and `make` packages. Open the **MSYS2
UCRT64** terminal, change to the repository, and build:

```sh
make release
./bin/pilang.exe help
```

### Linux and macOS

Linux and macOS runtime packages are not currently published. Their native
packaging will return after it is separately tested.

## Other build targets

```sh
make debug    # debug executable in bin/
make test     # build and run the test suite
make web      # browser/WebAssembly build; requires Emscripten
make clean    # remove generated build outputs
```
