# 1.4 Running Pilang

Pilang programs are usually saved in files with the `.pi` extension and run with the  `pilang.exe` interpreter.

If `pilang.exe` is not present, build it from the repository root:

```powershell
make release
```

## Run A File

On Windows, from the repository root:

```powershell
.\pilang.exe run test.pi
```

The executable also supports a shorthand form:

```powershell
.\pilang.exe test.pi
```

Both commands run the same file.

## Command Help

Use `help`, `--help`, or `-h` to display the current command list:

```powershell
.\pilang.exe help
```

Current commands include:

- `run <file>`: run a Pilang source file.
- `<file>`: shorthand for `run <file>`.
- `dis <file>`: print bytecode for a Pilang source file.
- `dis -o <output> <file>`: write bytecode to a file.
- `fmt <file>`: format a Pilang source file in place using the formatter in `utils/`.
- `min <file>`: minimize a Pilang source file in place using the minimizer in `utils/`.
- `help`: show command help.
- `--version` or `-v`: print the current interpreter version.

`fmt` and `min` rewrite the target file in place. For now they require Node.js and the formatter/minifier modules in the repository's `utils/` directory.

## Passing Arguments

Arguments after the script name are passed to the program and can be accessed through the system module.

```powershell
.\pilang.exe run app.pi first second
```

## Output Timing

The current native runner prints an execution-time line after running a program:

```text
Execution Time: 0.0000 ms
```

The exact timing depends on the program and machine.

## Example

println("Running Pilang");
