# 11.3 reduce

`reduce` folds a list into one value by repeatedly calling a function with an accumulator and the next item.

```pilang
result = reduce(list, reducer)
result = reduce(list, reducer, initial)
```

The reducer receives two arguments:

```pilang
reducer(accumulator, item)
```

The value returned by the reducer becomes the accumulator for the next item.

## Basic example

```pilang
numbers = [1, 2, 3, 4]

total = reduce(numbers, fn (acc, n) {
    return acc + n
}, 0)

print(total) // 10
```

## With an initial value

When an initial value is provided, reduction starts with that value.

```pilang
numbers = [2, 3, 4]

product = reduce(numbers, fn (acc, n) {
    return acc * n
}, 1)

print(product) // 24
```

The first call is:

```pilang
reducer(1, 2)
```

Then:

```pilang
reducer(2, 3)
reducer(6, 4)
```

## Without an initial value

When no initial value is provided, the first item becomes the initial accumulator and reduction starts at the second item.

```pilang
numbers = [10, 5, 2]

result = reduce(numbers, fn (acc, n) {
    return acc - n
})

print(result) // 3
```

This is evaluated like:

```pilang
((10 - 5) - 2)
```

For empty lists, provide an initial value. Reducing an empty list without an initial value is an error.

```pilang
total = reduce([], fn (acc, n) {
    return acc + n
}, 0)

print(total) // 0
```

## Building a list

The accumulator can be any value, including a list.

```pilang
numbers = [1, 2, 3]

labels = reduce(numbers, fn (acc, n) {
    acc = acc + ("item-" + n)
    return acc
}, [])

print(labels) // ["item-1", "item-2", "item-3"]
```

## Building a map

```pilang
pairs = [
    ["name", "Pilang"],
    ["type", "language"]
]

obj = reduce(pairs, fn (acc, pair) {
    acc[pair[0]] = pair[1]
    return acc
}, {})

print(obj["name"]) // "Pilang"
```

## Finding a maximum

```pilang
numbers = [8, 3, 11, 4]

max_value = reduce(numbers, fn (best, n) {
    if n > best {
        return n
    }

    return best
})

print(max_value) // 11
```

## Counting values

```pilang
words = ["pi", "lang", "pi", "docs"]

counts = reduce(words, fn (acc, word) {
    if !(word in acc) {
        acc[word] = 0
    }

    acc[word] += 1
    return acc
}, {})

print(counts["pi"]) // 2
```

## Notes

- `reduce` expects a list as the first argument.
- `reduce` expects a callable function as the second argument.
- The reducer is called from left to right.
- Use an initial value when the result type is different from the item type.
- Use an initial value when the list might be empty.
- Reducers are easiest to reason about when they return the next accumulator clearly.
