# 11.5 Iterators

Iterators let code process values one at a time instead of manually managing indexes everywhere. In Pilang, iteration appears in three common forms:

- `for ... in` loops over iterable values.
- Iterator objects can expose `iterator()` and `next()` behavior.
- The `func` module can create iterator-style functions such as `func.iterate`.

## for in

The most common iteration syntax is `for ... in`.

```swift
numbers = [1, 2, 3]

for n in numbers {
    println(n)
}
```

This works naturally with built-in iterable values such as lists, tuples, sets, strings, maps, ranges, and tensors. Custom classes can also participate by implementing `iterator()` and `next()`.

## Global `iter` and `next`

`iter(value, cycle=false)` creates a reusable iterator with its own traversal state. Calling `iter` on an existing iterator returns that same iterator.
`next(iterator, default=0)` returns the next item, or the default after exhaustion.

```swift
items = [10, 20]
it = iter(items)

println(next(it))                // 10
println(next(it))                // 20
println(next(it, default=-1))    // -1
```

Iterators over the same built-in collection advance independently. With `cycle=true`, an iterator starts over when it reaches the end:

```swift
it = iter(["red", "blue"], cycle=true)
println(next(it)) // red
println(next(it)) // blue
println(next(it)) // red
```

Cycling an empty iterable immediately returns the `next` default. A cycling iterator in a `for ... in` loop does not finish unless the loop exits with `break`.

## Iterating strings

Strings can be processed one character at a time.

```swift
for ch in "pilang" {
    println(ch)
}
```

String indexing wraps when the index is larger than the string length, but iteration walks the string in order.

## Iterating maps

Maps iterate over their keys.

```swift
user = {
    "name": "Mira",
    "role": "admin"
}

for key in user {
    println(key + ": " + user[key])
}
```

Use the key to access the value.

## Iterating sets

Sets contain unique values. Iteration visits the values in the set.

```swift
tags = {"docs", "lang", "docs"}

for tag in tags {
    println(tag)
}
```

Do not depend on set ordering unless the implementation of the specific set operation documents an order.

## Custom iterator protocol

Custom classes can participate in `for ... in` loops by implementing this protocol:

- `iterator()` returns an iterator object. It is called once at the beginning of each loop.
- `next()` returns the next value.
- `next()` returns `nil` when there are no more values.

The simplest iterator can return itself:

```swift
class Counter {
    constructor(limit) {
        this.limit = limit
        this.value = 0
    }

    iterator() {
        this.value = 0
        return this
    }

    next() {
        if this.value >= this.limit {
            return nil
        }

        current = this.value
        this.value += 1
        return current
    }
}

for n in Counter(3) {
    println(n) // 0, 1, 2
}
```

`iterator()` is invoked for each loop, so it can reset the iteration state. The loop invokes `next()` repeatedly until it returns `nil`. A `nil` value therefore marks the end and cannot also be yielded as an item.

For `for key, value in iterable`, `next()` should return a two-element list or tuple:

```swift
class IndexedValues {
    constructor() {
        this.index = 0
    }

    iterator() {
        this.index = 0
        return this
    }

    next() {
        if this.index >= 2 {
            return nil
        }

        index = this.index
        this.index += 1
        return [index, index * 10]
    }
}

for index, value in IndexedValues() {
    println(index, value)
}
```

## func.iterate

`func.iterate(seed, fun)` creates a function that returns a sequence of values. The first call returns the seed. Each later call returns the current value and advances the sequence by applying the function.

```swift
import func:f

next_power = f.iterate(1, n -> n * 2)

println(next_power()) // 1
println(next_power()) // 2
println(next_power()) // 4
println(next_power()) // 8
```

This is useful when you want lazy repeated _transformation without building a list first.

## Taking values from an iterator function

You can combine `func.iterate` with normal loops.

```swift
import func:f

next_value = f.iterate(10, n -> n + 10)
values = []

for i in range(0, 5) {
    values = values + next_value()
}

println(values) // [10, 20, 30, 40, 50]
```

## find

`find` is a functional search helper. It accepts a collection and a predicate.

```swift
index = find(collection, predicate)
```

For lists, it returns the index of the first matching item, or `-1` if no item matches.

```swift
numbers = [3, 7, 10, 12]

index = find(numbers, n -> n > 9)

println(index) // 2
```

For strings, the predicate receives each character as a string.

```swift
index = find("pilang", ch -> ch == "a")

println(index) // 3
```

## Checking iterability

The `col` module provides helpers for collection-like values, including checking whether a value is iterable.

```swift
import col:c

println(c.is_iterable([1, 2, 3])) // true
println(c.is_iterable(42)) // false
```

## Iterators and mutation

Be careful when mutating a collection while iterating over it.

```swift
numbers = [1, 2, 3]

for n in numbers {
    numbers = numbers + (n * 10)
}
```

Changing the iterable during iteration can make code harder to reason about. Prefer creating a new list with `map`, `filter`, or `reduce` when the goal is _transformation.

## Notes

- Use `for ... in` for normal collection traversal.
- Use `map`, `filter`, and `reduce` when you want expression-style _transformations.
- Use `func.iterate` for lazy repeated values.
- Use `find` when you need the first matching index.
- Custom iterators should clearly define how iteration ends.
