# 11.4 compose

Function composition builds a new function by connecting smaller functions together.

In Pilang, composition helpers are provided by the `func` built-in module.

```swift
import func:f
```

## compose

`f.compose` runs functions from right to left. The rightmost function receives the original arguments. Each earlier function receives the single result returned by the function after it.

```swift
import func:f

fn double(n) {
    return n * 2
}

fn add_one(n) {
    return n + 1
}

calc = f.compose(add_one, double)

print(calc(10)) // 21
```

The call above is equivalent to:

```swift
add_one(double(10))
```

## pipe

`f.pipe` runs functions from left to right. It is often easier to read when you want data to flow in the same order as the code.

```swift
import func:f

calc = f.pipe(
    n -> n * 2,
    n -> n + 1,
    n -> "result: " + n
)

print(calc(10)) // "result: 21"
```

This is equivalent to:

```swift
"result: " + ((10 * 2) + 1)
```

## Pipeline Operator

The `=>` operator immediately sends the value on the left into the function or
function call on the right.

```swift
result = [1, 2, 3, 4] =>
    filter(n -> n % 2 == 0) =>
    map(n -> n * 2) =>
    reduce((acc, n) -> acc + n)

print(result) // 12
```

This is equivalent to:

```swift
result = reduce(
    map(
        filter([1, 2, 3, 4], n -> n % 2 == 0),
        n -> n * 2
    ),
    (acc, n) -> acc + n
)
```

A stage without parentheses calls the function value with the previous result:

```swift
fn double(n) {
    return n * 2
}

print(3 => double) // 6
```

Pipeline stages currently support normal positional arguments. Spread and named
arguments can still be used in ordinary calls outside a pipeline.

## Multiple arguments

For `compose`, the rightmost function can receive all original arguments.

```swift
import func:f

fn add(a, b) {
    return a + b
}

fn square(n) {
    return n * n
}

square_sum = f.compose(square, add)

print(square_sum(2, 3)) // 25
```

For `pipe`, the first function receives all original arguments.

```swift
import func:f

square_sum = f.pipe(add, square)
print(square_sum(2, 3)) // 25
```

## partial

`f.partial` binds leading arguments and returns a new function.

```swift
import func:f

fn power(base, exponent) {
    return base ** exponent
}

square = f.partial(power, 2)

print(square(8)) // 256
```

The bound value `2` becomes the first argument.

## curry

`f.curry` turns a function into a chain of smaller calls. It can infer the arity from the function, or you can pass the arity explicitly.

```swift
import func:f

fn add3(a, b, c) {
    return a + b + c
}

curried = f.curry(add3)

print(curried(1)(2)(3)) // 6
```

With explicit arity:

```swift
import func:f

fn join3(a, b, c) {
    return a + "-" + b + "-" + c
}

join_names = f.curry(join3, 3)
print(join_names("pi")("lang")("docs")) // "pi-lang-docs"
```

## spread and unspread

`f.spread` converts a function that expects positional arguments into a function that accepts one list.

```swift
import func:f

fn add(a, b) {
    return a + b
}

add_pair = f.spread(add)

print(add_pair([2, 3])) // 5
```

`f.unspread` converts a function that expects one list into a function that accepts positional arguments.

```swift
import func:f

fn sum_list(values) {
    return reduce(values, fn (acc, n) {
        return acc + n
    }, 0)
}

sum_args = f.unspread(sum_list)

print(sum_args(1, 2, 3, 4)) // 10
```

## juxt

`f.juxt` runs several functions with the same arguments and returns a list of their results.

```swift
import func:f

stats = f.juxt(
    values -> len(values),
    values -> reduce(values, fn (acc, n) { return acc + n }, 0),
    values -> reduce(values, fn (best, n) {
        if n > best {
            return n
        }

        return best
    })
)

print(stats([3, 7, 2])) // [3, 12, 7]
```

## Choosing compose or pipe

Use `compose` when you are describing nested calls:

```swift
import func:f

clean_name = f.compose(
    text -> text.upper(),
    text -> text.trim()
)
```

Use `pipe` when you are describing a sequence of _transformations:

```swift
import func:f

clean_name = f.pipe(
    text -> text.trim(),
    text -> text.upper()
)
```

Both examples trim first and uppercase second. The difference is the direction in which the functions are written.

## Notes

- `compose` and `pipe` return functions.
- `=>` immediately calls each stage and returns the final value.
- In `compose`, the rightmost function receives the original call arguments.
- In `pipe`, the leftmost function receives the original call arguments.
- After the first step, each function receives one value: the previous result.
- For data-heavy collection work, combine composition with `map`, `filter`, and `reduce`.
