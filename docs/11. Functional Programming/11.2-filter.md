# 11.2 filter

`filter` keeps only the items that pass a predicate function.

```pilang
result = filter(list, predicate)
```

The predicate is called once for each item:

```pilang
predicate(item)
```

If the predicate returns a truthy value, the item is included in the result. If it returns a falsey value, the item is skipped.

## Basic example

```pilang
numbers = [1, 2, 3, 4, 5, 6]
evens = filter(numbers, n -> n % 2 == 0)

print(evens) // [2, 4, 6]
```

## Predicate functions

A predicate can be an arrow function:

```pilang
positive = filter([-2, -1, 0, 1, 2], n -> n > 0)
```

It can also be a block function:

```pilang
words = ["", "pi", "lang", ""]

non_empty = filter(words, fn (word) {
    return len(word) > 0
})

print(non_empty) // ["pi", "lang"]
```

Or a named function:

```pilang
fn is_adult(user) {
    return user["age"] >= 18
}

users = [
    {"name": "Ava", "age": 22},
    {"name": "Noor", "age": 16}
]

adults = filter(users, is_adult)
```

## Truthy and falsey results

The predicate does not have to return a boolean. Any value is tested using Pilang truthiness rules.

```pilang
values = [0, 1, 2, nil, "", "ok"]

truthy_values = filter(values, item -> item)
print(truthy_values) // [1, 2, "ok"]
```

Common falsey values include:

- `false`
- `nil`
- `0`
- empty strings
- empty collections

## Keeping original items

`filter` does not clone the items. It returns a new list containing the original matching values.

```pilang
users = [
    {"name": "Mira", "active": true},
    {"name": "Sam", "active": false}
]

active_users = filter(users, user -> user["active"])

active_users[0]["name"] = "Mira Changed"
print(users[0]["name"]) // "Mira Changed"
```

This matters for maps, objects, lists, tensors, and other mutable values.

## Combining filter and map

```pilang
orders = [
    {"total": 20, "paid": true},
    {"total": 35, "paid": false},
    {"total": 50, "paid": true}
]

paid_totals = map(
    filter(orders, order -> order["paid"]),
    order -> order["total"]
)

print(paid_totals) // [20, 50]
```

## Notes

- `filter` expects a list as the first argument.
- `filter` expects a callable function as the second argument.
- The result list can be shorter than the input list.
- If no items pass the predicate, the result is `[]`.
- The predicate should avoid side effects unless mutation is intentional.
