# 11.1 map

`map` _transforms every item in a list and returns a new list containing the _transformed values.

```pilang
result = map(list, callback)
```

The callback is called once for each item:

```pilang
callback(item)
```

## Basic example

```pilang
numbers = [1, 2, 3, 4]
squares = map(numbers, n -> n * n)

print(squares) // [1, 4, 9, 16]
```

`map` does not change the list itself:

```pilang
numbers = [1, 2, 3]
doubled = map(numbers, n -> n * 2)

print(numbers) // [1, 2, 3]
print(doubled) // [2, 4, 6]
```

## Callback forms

You can pass an arrow function:

```pilang
names = ["pi", "lang"]
upper = map(names, name -> name.upper())
```

You can pass an anonymous function:

```pilang
prices = [10, 20, 30]
with_tax = map(prices, fn (price) {
    return price * 1.15
})
```

You can also pass a named function:

```pilang
fn square(n) {
    return n * n
}

values = map([2, 3, 4], square)
```

## Mapping objects and maps

When list items are maps or objects, the callback receives each item.

```pilang
users = [
    {"name": "Mira", "active": true},
    {"name": "Sam", "active": false}
]

names = map(users, user -> user["name"])
print(names) // ["Mira", "Sam"]
```

If the callback mutates an object item, that mutation affects the object itself because the object is shared:

```pilang
users = [{"score": 1}, {"score": 2}]

map(users, fn (user) {
    user["score"] += 10
    return user
})

print(users) // [{"score": 11}, {"score": 12}]
```

Use pure callbacks when you want predictable _transformations.

## Closures with map

Callbacks can capture variables from surrounding scope.

```pilang
fn make_multiplier(factor) {
    return n -> n * factor
}

triple = make_multiplier(3)
values = map([1, 2, 3], triple)

print(values) // [3, 6, 9]
```

## Returning different types

The mapped value does not need to have the same type as the input item.

```pilang
numbers = [1, 2, 3]
labels = map(numbers, n -> "item-" + n)

print(labels) // ["item-1", "item-2", "item-3"]
```

## Chaining with other helpers

`map` is often used after `filter` and before `reduce`.

```pilang
numbers = [1, 2, 3, 4, 5, 6]

total = reduce(
    map(
        filter(numbers, n -> n % 2 == 0),
        n -> n * n
    ),
    fn (acc, n) {
        return acc + n
    },
    0
)

print(total) // 56
```

## Notes

- `map` expects a list as the first argument.
- `map` expects a callable function as the second argument.
- The callback receives one item at a time.
- The result list has the same length as the input list.
- Empty lists return empty lists.
