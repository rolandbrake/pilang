# 3.11 Sets

Sets store unique values. They are written with braces containing values without `key: value` pairs.

```swift
let numbers = {1, 2, 3};
let names = {"Ada", "Grace", "Linus"};
```

Duplicate values collapse into one set entry.

```swift
let values = {1, 1, 2};
println(values); // {1, 2}
```

Set literals support integer fill expansion:

```swift
let digits = {1, ..., 5};

println(3 in digits); // true
```

The fill can count up or down, but sets are unordered, so iteration and printing
do not promise the same order as the source literal.

Sets are useful for membership checks, deduplication, and set algebra such as union and intersection. They do not preserve insertion order.

## Empty Set

`{}` creates an empty map, not an empty set.

```swift
let map = {};
```

To build an empty set, use `set()`.

```swift
let empty = set();
let unique = set([1, 1, 2, 3]);

println(unique); // {1, 2, 3}
```

`set(value)` accepts iterable values such as lists, tuples, strings, and other sets.

## Membership

Use `in` to test whether a set contains a value.

```swift
let allowed = {"read", "write"};

println("read" in allowed);  // true
println("admin" in allowed); // false
```

The `contains` helper provides the same kind of check.

```swift
let allowed = {"read", "write"};

println(contains(allowed, "write")); // true
```

## Adding And Removing Values

Use collection helpers to mutate a set.

```swift
import col.{add, clear};

let values = {1, 2};

add(values, 3);
println(values); // {1, 2, 3}

remove(values, 2);
println(values); // {1, 3}

clear(values);
println(values); // {}
```

Adding a value that already exists leaves the set unchanged.

Call `add` or `remove` once for each value you want to change.

```swift
import col.{add};

let values = {1};

add(values, 2);
add(values, 3);
remove(values, 1);

println(values); // {2, 3}
```

## Length And Copying

Use `len` for size, and `copy` when you need a separate set with the same members.

```swift
let values = {1, 2, 3};
let cloned = copy(values);

println(len(values)); // 3
println(cloned);      // {1, 2, 3}
```

## Set Operations

Pilang includes helpers for common set algebra.

```swift
let a = {1, 2, 3};
let b = {3, 4, 5};

println(union(a, b));          // values in either set
println(intersection(a, b));   // values in both sets
println(difference(a, b));     // values in a but not b
println(symmetric_diff(a, b)); // values in exactly one set
```

Set operators are available for the same operations.

```swift
let a = {1, 2, 3};
let b = {3, 4, 5};

println(a | b); // union
println(a & b); // intersection
println(a - b); // difference
println(a ^ b); // symmetric difference
```

Use subset and superset helpers when comparing relationships between sets.

```swift
let small = {1, 2};
let large = {1, 2, 3};

println(issubset(small, large));   // true
println(issuperset(large, small)); // true
println(small <= large);           // true
println(large >= small);           // true
```

`isdisjoint(a, b)` returns whether two sets share no values.

## Native Methods

Several set helpers can also be called with dot syntax. The set before the dot
is passed as the first argument to the same native function.

```swift
let values = set([1, 2]);

values.add(3);

println(values.length());       // 3
println(values.includes(2));    // true
println(values.union({3, 4}));  // {1, 2, 3, 4}
```

These two forms are equivalent:

```swift
union(left, right);
left.union(right);
```

Supported set methods include `add`, `clear`, `len`, `length`, `contains`,
`includes`, `union`, `intersection`, `difference`, `symmetric_diff`,
`symmetricDiff`, `issubset`, `isSubset`, `issuperset`, `isSuperset`,
`isdisjoint`, and `isDisjoint`.

## Iteration

Sets are iterable, but they are unordered.

```swift
for value in {"red", "green", "blue"} {
    println(value);
}
```

Do not rely on the order of values produced from a set.

## Values And Equality

Set membership is based on value equality. Two equal values collapse into one member, and set operations compare members by value.

```swift
let ids = {10, 20, 10};

println(len(ids)); // 2
println(10 in ids); // true
```

When output order matters, convert or copy the values into an ordered collection before displaying or comparing the sequence.
