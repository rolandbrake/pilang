# 3.8 Ranges

Ranges represent numeric sequences and are commonly used in `for` loops.

```swift
for i in 1..5 {
    println(i);
}
```

Ranges print in the same compact form:

```swift
println(1..5);    // 1..5
println(1..5:2);  // 1..5:2
```

The range end is exclusive when iterating.

```swift
for i in 0..3 {
    println(i); // 0, then 1, then 2
}
```

## Step

Add `:step` after the range to control the increment.

```swift
for i in 0..10:2 {
    println(i); // 0, 2, 4, 6, 8
}
```

Negative steps count downward.

```swift
for i in 5..0:-1 {
    println(i); // 5, 4, 3, 2, 1
}
```

## Membership

Use `in` to test whether a number belongs to a range.

```swift
println(4 in 0..10:2); // true
println(5 in 0..10:2); // false
```
