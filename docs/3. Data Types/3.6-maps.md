# 3.6 Maps

Maps store key-value pairs. They are also used as object-like values in Pilang.

```pilang
let user = {
    "name": "Ada",
    "active": true
};
```

An empty brace literal creates an empty map.

```pilang
let data = {};
```

Keys are usually strings or identifiers in object-style code. Values can be any
Pilang value, including lists, maps, functions, classes, and `nil`.

```pilang
let user = {
    name: "Ada",
    scores: [10, 20, 30],
    meta: {active: true}
};
```

## Access

Use bracket access for keys.

```pilang
let user = {"name": "Ada"};
println(user["name"]);
```

Maps can also be used with dot-style member access for object-like fields when
the key is an identifier-style name.

```pilang
let point = {};
point.x = 10;
point.y = 20;

println(point.x);
```

Bracket access is the safer form when the key is stored in a variable or is not
a simple identifier.

```pilang
let key = "display name";
let user = {};

user[key] = "Ada Lovelace";

println(user[key]);
```

Dot access uses the literal field name after the dot. It does not read a key
variable.

```pilang
let field = "name";
let user = {name: "Ada"};

println(user.name);   // Ada
println(user[field]); // Ada
```

## Assignment

Assigning to a map key creates or replaces that key.

```pilang
let settings = {};
settings["theme"] = "dark";
settings["theme"] = "light";
```

Dot assignment works for identifier-style field names.

```pilang
let settings = {};

settings.theme = "dark";
settings.debug = true;
```

Assignments mutate the existing map object.

```pilang
let a = {count: 1};
let b = a;

b.count = 2;

println(a.count); // 2
```

## Length And Membership

Use `#` to count map entries and `in` to test whether a key exists.

```pilang
let user = {"name": "Ada", "active": true};

println(#user);
println("name" in user); // true
```

Membership checks keys, not values.

```pilang
let user = {name: "Ada", active: true};

println("Ada" in user);  // false
println("name" in user); // true
```

## Spread And Merge

Use `...` inside a map literal to copy entries from another map into the new
map.

```pilang
let base = {theme: "dark", debug: false};
let local = {...base, debug: true};

println(local.theme); // dark
println(local.debug); // true
```

Map spreads are applied in order. Later entries replace earlier entries with the
same key.

```pilang
let left = {a: 1, b: 2};
let right = {b: 7, d: 9};

let merged = {start: 0, ...left, mid: 4, ...right, end: 10};

println(merged.a);        // 1
println(merged.b);        // 7
println(merged["start"]); // 0
println(merged["end"]);   // 10
```

Normal entries can appear before, between, and after spreads. This makes spreads
useful for defaults plus overrides.

```pilang
let defaults = {
    host: "localhost",
    port: 8000,
    debug: false
};

let config = {...defaults, port: 9000};

println(config.port); // 9000
```

Spread copies entries into a new map. It does not deep-clone nested lists or
nested maps.

```pilang
let base = {tags: ["core"]};
let copy = {...base};

copy.tags[0] = "changed";

println(base.tags[0]); // changed
```

## Maps In Lists

Lists of maps are common for tabular or record-like data.

```pilang
let users = [
    {name: "Ada", active: true},
    {name: "Grace", active: false},
    {name: "Mira", active: true}
];

println(users[0].name); // Ada
```

Use a list comprehension to extract or filter fields.

```pilang
let active_names = [user.name : user in users : user.active];

println(active_names); // ["Ada", "Mira"]
```

You can combine map spread with a list comprehension to create updated records
without changing the original maps.

```pilang
let activated = [{...user, active: true} : user in users];

println(activated[1].active); // true
println(users[1].active);     // false
```

## Lists Inside Maps

Maps can contain lists when one record needs several ordered values.

```pilang
let report = {
    title: "scores",
    values: [10, 20, 30]
};

report.values[1] = 99;

println(report.values); // [10, 99, 30]
```

Use nested indexing when you need to work with a map inside a list or a list
inside a map.

```pilang
let data = {
    users: [
        {name: "Ada"},
        {name: "Mira"}
    ]
};

println(data.users[1].name); // Mira
```

## Object-Style Methods

Maps can store functions and act as object-like values. Method syntax is covered
in the objects and classes chapter, but the shape starts with an ordinary map.

```pilang
let counter = {
    value: 0,

    next() {
        this.value = this.value + 1;
        return this.value;
    }
};

println(counter.next()); // 1
println(counter.next()); // 2
```

Use a class when you want a stricter named prototype. Use a map literal when you
want a lightweight object-like value.
