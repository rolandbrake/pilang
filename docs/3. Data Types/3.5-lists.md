# 3.5 Lists

Lists are ordered, mutable collections. They can hold any mix of values:
numbers, strings, booleans, maps, functions, objects, other lists, and `nil`.

```pilang
let numbers = [1, 2, 3];
let mixed = [1, "two", true, nil];
let empty = [];
```

List order is preserved. The first value has index `0`, the second has index
`1`, and so on.

```pilang
let names = ["Ada", "Grace", "Mira"];

println(names[0]); // Ada
println(names[1]); // Grace
```

## Indexing

Use square brackets to access an item by index.

```pilang
let items = ["a", "b", "c"];

println(items[0]);  // a
println(items[-1]); // c
```

Indexes are zero-based. Negative indexes count from the end.

Indexes wrap around the list length. If an index is larger than the list, Pilang rounds it back into the valid range.

```pilang
let items = ["a", "b", "c"];

println(items[3]); // a
println(items[4]); // b
```

Index wrapping is convenient, but it can also hide mistakes. If an index comes
from user input or a calculation, check it explicitly when out-of-range access
should be treated as an error in your program.

## Assignment

Lists are mutable, so you can assign to an item.

```pilang
let items = [10, 20, 30];
items[1] = 99;
println(items); // [10, 99, 30]
```

Assignment changes the existing list object. Any other variable that refers to
the same list sees the change.

```pilang
let left = [1, 2];
let same = left;

same[0] = 99;

println(left); // [99, 2]
```

## Length

Use the `#` operator to get the number of items.

```pilang
let items = [1, 2, 3];
println(#items); // 3
```

## Slicing

Lists support slice syntax.

```pilang
let items = [0, 1, 2, 3, 4];

println(items[:3]);    // [0, 1, 2]
println(items[2:]);    // [2, 3, 4]
println(items[::2]);   // [0, 2, 4]
println(items[::-1]);  // [4, 3, 2, 1, 0]
```

Slice syntax is `start:end:step`. Any part can be omitted.

```pilang
let items = [0, 1, 2, 3, 4, 5];

println(items[1:4]);  // [1, 2, 3]
println(items[:2]);   // [0, 1]
println(items[3:]);   // [3, 4, 5]
println(items[::2]);  // [0, 2, 4]
```

Assigning to a slice replaces that part of the list.

```pilang
let items = [0, 1, 2, 3];

items[1:3] = [8, 9];

println(items); // [0, 8, 9, 3]
```

Extended slice assignment, such as `items[0:4:2] = [7, 6]`, expects the
replacement length to match the number of selected positions.

## Comprehensions

Comprehensions build a new list by iterating over one or more iterable values.
The general shape is:

```pilang
[result_expression : name in iterable]
```

For example:

```pilang
let evens = [x * 2 : x in 0..5];

println(evens); // [0, 2, 4, 6, 8]
```

The expression before the first `:` produces each output item. The `name in
iterable` part chooses the input values.

Comprehensions can include filters after another `:`. Only values that pass the
filter are emitted.

```pilang
let squares = [x * x : x in 0..10 : x % 2 == 0];

println(squares); // [0, 4, 16, 36, 64]
```

Multiple filters can be separated with commas.

```pilang
let small = [x : x in 0..20 : x > 3, x < 8];

println(small); // [4, 5, 6, 7]
```

Comprehensions can also have multiple iterators. The inner iterator varies
fastest, so the output is produced for each combination in order.

```pilang
let pairs = [[x, y] : x in 0..3, y in 0..3];

println(pairs);
// [[0, 0], [0, 1], [0, 2], [1, 0], [1, 1], [1, 2], [2, 0], [2, 1], [2, 2]]
```

You can combine multiple iterators and filters.

```pilang
let even_pairs = [
    [x, y] : x in 0..5, y in 0..5 : x % 2 == 0, y % 2 == 0
];

println(#even_pairs); // 9
```

Comprehension variables are local to the comprehension expression.

```pilang
let values = [x * 2 : x in 1..4];

// x is not available here
```

## Spreading Into Lists

Use `...` inside a list literal to expand another iterable into the new list.

```pilang
let base = [2, 3];
let merged = [1, ...base, 4];

println(merged); // [1, 2, 3, 4]
```

Spread works with iterable values. Strings expand into one-character strings.

```pilang
let chars = [..."pi"];

println(chars); // ["p", "i"]
```

Spreading copies the item references into the new list. It does not deep-clone
nested lists or objects.

```pilang
let rows = [[1, 2], [3, 4]];
let copy = [...rows];

copy[0][0] = 99;

println(rows[0][0]); // 99
```

To combine several lists, place spreads and normal values in the order you want.

```pilang
let left = [1, 2];
let right = [4, 5];

let all = [0, ...left, 3, ...right, 6];

println(all); // [0, 1, 2, 3, 4, 5, 6]
```

## Lists And Function Calls

The same spread operator can expand a list into positional arguments.

```pilang
fun add(a, b) {
    return a + b;
}

let args = [2, 5];

println(add(...args)); // 7
```

This is useful with functions that return or receive list-shaped groups of
values.

```pilang
fun pair(a, b) {
    return [a, b];
}

[first, second] = pair(...[8, 5]);

println(first);  // 8
println(second); // 5
```

## Lists And Maps

Lists are ordered by position. Maps are keyed by name or value. Use a list when
order matters; use a map when lookup by key matters.

```pilang
let users = [
    {name: "Ada", active: true},
    {name: "Grace", active: false}
];

println(users[0].name);      // Ada
println(users[1]["active"]); // false
```

Comprehensions are often useful for lists of maps.

```pilang
let users = [
    {name: "Ada", active: true},
    {name: "Grace", active: false},
    {name: "Mira", active: true}
];

let active_names = [user.name : user in users : user.active];

println(active_names); // ["Ada", "Mira"]
```

You can also use a list of pairs to build or update map-like data manually.

```pilang
let pairs = [["theme", "dark"], ["debug", true]];
let settings = {};

for pair in pairs {
    settings[pair[0]] = pair[1];
}

println(settings["theme"]); // dark
```

Map spreading is documented in the maps section, but it pairs naturally with
lists when you have list data that contains maps.

```pilang
let base_user = {active: true};
let users = [
    {...base_user, name: "Ada"},
    {...base_user, name: "Mira"}
];

println(users[0].active); // true
```
