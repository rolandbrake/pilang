# 3.2 Strings

Strings store text. Use single quotes or double quotes.

```pilang
let name = "Pilang";
let letter = 'p';
```

Strings can be concatenated with `+`.

```pilang
let greeting = "Hello, " + name;
println(greeting);
```

## Indexing

Indexing a string returns a one-character string.

```pilang
let text = "hello";
println(text[0]); // h
```

Negative indexes count from the end.

```pilang
println(text[-1]); // o
```

Indexes wrap around the string length. If an index is larger than the string, Pilang rounds it back into the valid range.

```pilang
let text = "abc";
println(text[3]); // a
println(text[4]); // b
```

## Slicing

Strings support slice syntax.

```pilang
let text = "abcdef";

println(text[:3]);   // abc
println(text[3:]);   // def
println(text[1:5:2]); // bd
```

## Length

Use the `#` operator to get the length of a string.

```pilang
println(#"Pilang");
```

## Membership

Use `in` to test whether one string contains another.

```pilang
println("lang" in "Pilang"); // true
```

## Native Methods

Several string built-ins can also be called with dot syntax. The string before
the dot is passed as the first argument to the same native function.

```pilang
println("  Pilang  ".trim()); // Pilang
println("Pilang".upper());    // PILANG
println("Pilang".lower());    // pilang
```

These two forms are equivalent:

```pilang
trim("  text  ");
"  text  ".trim();
```

Supported string methods include `trim`, `upper`, `lower`, `append`, `push`,
`pop`, `peek`, `len`, `contains`, `index`, `count`, `repeat`, `copy`, and
`reverse`.
