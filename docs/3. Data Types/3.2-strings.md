# 3.2 Strings

Strings store text. Use single quotes or double quotes.

```swift
let name = "Pilang";
let letter = 'p';
```

Strings can be concatenated with `+`.

```swift
let greeting = "Hello, " + name;
println(greeting);
```

## String Constant Sharing

The compiler interns string constants: repeated names and equal decoded string
literals share one string object within a compiler's constant pool. The lookup
happens before allocating a string object. Each module has its own compiler pool;
REPL inputs reuse their existing pool.

Runtime operations such as concatenation still create strings normally. Use `==`
to compare text; equal strings are not guaranteed to have the same `id()`.

## Indexing

Indexing a string returns a one-character string.

```swift
let text = "hello";
println(text[0]); // h
```

Negative indexes count from the end.

```swift
println(text[-1]); // o
```

Indexes must refer to an existing character. An index outside the string
boundary is a runtime error. Negative indexes count from the end.

```swift
let text = "abc";
println(text[3]); // a
println(text[4]); // b
```

## Slicing

Strings support slice syntax.

```swift
let text = "abcdef";

println(text[:3]);   // abc
println(text[3:]);   // def
println(text[1:5:2]); // bd
```

## Length

Use the `#` operator to get the length of a string.

```swift
println(#"Pilang");
```

## Membership

Use `in` to test whether one string contains another.

```swift
println("lang" in "Pilang"); // true
```

## Native Methods

Several string built-ins can also be called with dot syntax. The string before
the dot is passed as the first argument to the same native function.

```swift
println("  Pilang  ".trim()); // Pilang
println("Pilang".upper());    // PILANG
println("Pilang".lower());    // pilang
```

These two forms are equivalent:

```swift
trim("  text  ");
"  text  ".trim();
```

Supported string methods include `trim`, `upper`, `lower`, `append`, `push`,
`pop`, `peek`, `len`, `length`, `contains`, `includes`, `index`, `indexOf`,
`count`, `repeat`, `copy`, and `reverse`.
