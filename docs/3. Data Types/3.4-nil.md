# 3.4 Nil

`nil` represents the absence of a value.

```pilang
let result = nil;
```

Variables declared without an initializer start as `nil`.

```pilang
let pending;
println(pending); // nil
```

## Common Uses

Use `nil` when a value is missing, optional, not found, or not computed yet.

```pilang
fun find_user(name = "") {
    return nil;
}

let user = find_user("Ada");
if user == nil {
    println("not found");
}
```

## Truthiness

`nil` is falsey.

```pilang
if !nil {
    println("nil is falsey");
}
```
