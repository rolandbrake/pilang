# 3.1 Numbers

Pilang uses numbers for integer-style and floating-point arithmetic.

```pilang
let count = 10;
let price = 12.5;
let ratio = .75;
```

Numbers support arithmetic, comparison, bitwise operations, ranges, indexing expressions, and numeric built-ins.

```pilang
let total = 10 + 5 * 2;
let average = total / 3;
let power = 2 ** 8;
```

## Numeric Literals

Decimal literals are the most common form.

```pilang
let a = 42;
let b = 3.14;
let c = 1e6;
let d = 2.5e-3;
```

Pilang also recognizes hexadecimal, octal, and binary literals.

```pilang
let hex = 0xFF;
let oct = 0o755;
let bin = 0b1010;
```

Decimal integers cannot use leading zeros.

```pilang
// Invalid decimal style
let n = 012;
```

## Special Numbers

`INF` and `NAN` are built-in numeric constants.

```pilang
let infinity = INF;
let invalid = NAN;
```

## Numeric Truthiness

The number `0` is falsey in logical contexts. Other numbers are truthy.

```pilang
if 0 {
    println("not printed");
}
```
