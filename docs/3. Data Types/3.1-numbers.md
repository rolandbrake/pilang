# 3.1 Numbers

Pilang uses numbers for integer-style and floating-point arithmetic.

```swift
let count = 10;
let price = 12.5;
let ratio = .75;
```

Numbers support arithmetic, comparison, bitwise operations, ranges, indexing expressions, and numeric built-ins.

```swift
let total = 10 + 5 * 2;
let average = total / 3;
let power = 2 ** 8;
```

## Numeric Literals

Decimal literals are the most common form.

```swift
let a = 42;
let b = 3.14;
let c = 1e6;
let d = 2.5e-3;
```

### Numeric Separators

Use `_` between decimal digits to make long literals easier to read. Separators
do not change the numeric value and may also be used in fractional and exponent
parts.

```swift
let population = 100_000_000;
let price = 1_234.5_6;
let scale = 1.2_5e+0_3;
```

Each separator must appear between digits. For example, `1_000` is valid, while
`1_` and `1__000` are invalid.

Pilang also recognizes hexadecimal, octal, and binary literals.

```swift
let hex = 0xFF;
let oct = 0o755;
let bin = 0b1010;
```

Decimal integers cannot use leading zeros.

```swift
// Invalid decimal style
let n = 012;
```

## Special Numbers

`INF` and `NAN` are built-in numeric constants.

```swift
let infinity = INF;
let invalid = NAN;
```

## Number Display

When a number is printed, ordinary-sized values use decimal notation instead of
scientific notation.

```swift
println(102334000); // 102334000
```

Very large or tiny values may still use scientific notation to keep their text
representation readable.

## Numeric Truthiness

The number `0` is falsey in logical contexts. Other numbers are truthy.

```swift
if 0 {
    println("not printed");
}
```
