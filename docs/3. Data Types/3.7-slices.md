# 3.7 Slices

Slices select part of a sequence. Pilang supports slices for lists, tuples, and strings.

```swift
sequence[start:stop:step]
```

Each part is optional.

```swift
items[:stop];
items[start:];
items[start:stop];
items[start:stop:step];
items[::step];
```

## Lists

```swift
let items = [0, 1, 2, 3, 4, 5];

println(items[1:4]);  // [1, 2, 3]
println(items[:3]);   // [0, 1, 2]
println(items[3:]);   // [3, 4, 5]
```

## Strings

```swift
let text = "abcdef";

println(text[1:4]); // bcd
println(text[::-1]); // fedcba
```

## Tuples

Slicing a tuple returns a tuple.

```swift
let values = (10, 20, 30, 40);
println(values[1:3]); // (20, 30)
```

## Step

The step controls how far the slice moves after each item. A negative step walks backward.

```swift
let items = [0, 1, 2, 3, 4];

println(items[::2]);  // [0, 2, 4]
println(items[::-1]); // [4, 3, 2, 1, 0]
```

A slice step cannot be zero.
