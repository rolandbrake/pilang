# 3.10 Tuples

Tuples are ordered collections written with parentheses. They are useful when you want a fixed group of values.

```pilang
let point = (10, 20);
let record = ("Ada", 37, true);
```

Tuples preserve insertion order and can contain mixed value types. They are best for small, fixed-size groupings such as coordinates, return values, configuration pairs, or records where each position has a known meaning.

Unlike lists, tuples are not meant to be edited in place. Build a new tuple when you need a changed sequence.

## Empty And Single-Item Tuples

An empty tuple is `()`.

```pilang
let empty = ();
```

A single-item tuple needs a trailing comma so it is not confused with a grouped expression.

```pilang
let one = (42,);
let grouped = (42);
```

`one` is a tuple. `grouped` is just the number `42`.

## Creating Tuples From Values

Use the `tuple` helper to create a tuple from existing values or from another compatible collection.

```pilang
let empty = tuple();
let from_list = tuple([1, 2, 3]);
let from_values = tuple("x", "y", "z");
```

Tuple literals also support integer fill expansion:

```pilang
let ids = (3, ..., 6);

println(ids); // (3, 4, 5, 6)
```

Both endpoints must be integer numeric literals.

## Indexing

Use square brackets to read tuple items.

```pilang
let pair = ("left", "right");

println(pair[0]);  // left
println(pair[-1]); // right
```

Indexes wrap around the tuple length. If an index is larger than the tuple, Pilang rounds it back into the valid range.

```pilang
let values = ("a", "b", "c");

println(values[3]); // a
println(values[4]); // b
```

Tuples support the same negative-index behavior as lists.

## Slicing

Slicing a tuple returns a tuple.

```pilang
let values = (1, 2, 3, 4);
println(values[1:3]); // (2, 3)
println(values[:2]);  // (1, 2)
println(values[::-1]); // (4, 3, 2, 1)
```

You can also pass a slice object into tuple indexing.

```pilang
let values = (1, 2, 3, 4);
println(values[slice(1, 3)]); // (2, 3)
```

## Length And Search

Use collection helpers to inspect tuple contents.

```pilang
let values = ("a", "b", "a");

println(len(values));           // 3
println(contains(values, "b")); // true
println(index(values, "a"));    // 0
println(count(values, "a"));    // 2
```

`index` returns the first matching position, or `-1` when the value is not present.

## Combining And Repeating

Tuples can be concatenated or repeated.

```pilang
let a = (1, 2);
let b = (3, 4);

println(a + b);        // (1, 2, 3, 4)
println(concat(a, b)); // (1, 2, 3, 4)
println(a * 3);        // (1, 2, 1, 2, 1, 2)
println(repeat(a, 2)); // (1, 2, 1, 2)
```

These operations return new tuples.

## Iteration

Tuples are iterable.

```pilang
for value in ("a", "b", "c") {
    println(value);
}
```

## Common Uses

Tuples are useful when positions matter and the group should travel together.

```pilang
let size = (1920, 1080);
let user = ("Ada", "admin", true);

println(size[0]); // width
println(user[1]); // role
```

For large collections where you will add, remove, or replace items frequently, prefer a list.
