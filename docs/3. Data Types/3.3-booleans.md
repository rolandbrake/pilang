# 3.3 Booleans

Booleans represent truth values. Pilang has two boolean literals: `true` and `false`.

```pilang
let ready = true;
let done = false;
```

## Boolean Operators

Use logical operators to combine boolean expressions.

```pilang
let can_run = ready && !done;
let should_wait = !ready || done;
```

Comparison operators produce booleans.

```pilang
println(10 > 5);     // true
println("a" == "b"); // false
```

## Truthiness

Values are converted to booleans in conditionals and logical expressions.

```pilang
if ready {
    println("ready");
}
```

For numbers, `0` is falsey and nonzero numbers are truthy. `nil` is falsey. Collections and objects use runtime truthiness rules for their type.
