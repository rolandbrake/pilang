# 7.2 Maps

Maps are primitive key-value collections for records, configuration, and lookup
tables. They are separate from class values and class instances.

```swift
let user = {
    name: "Ada",
    age: 36,
    active: true,
}

println(user.name)
println(user["age"])
```

## Map Operations

Maps support `get`, `set`, `has`, `delete`, `keys`, and `values`.

```swift
let settings = {theme: "dark"}

settings.set("debug", true)
println(settings.get("theme"))
println(settings.has("debug"))
println(settings.keys())
settings.delete("debug")
```

Maps are mutable. Map spread creates a new map containing entries from the
source maps.

```swift
let base = {host: "localhost", port: 8080}
let config = {...base, debug: true}
```

## Maps Are Not Classes

A map literal does not create a class, an instance, or an inheritance
relationship. A map can contain function values, but those functions are not
automatically bound to `this` as class methods.

Use a class when you need constructors, bound methods, inheritance, class
fields, locking, or operator/magic methods.

```swift
class Player {
    constructor(name) {
        this.name = name
    }

    label() {
        return "Player(" + this.name + ")"
    }
}

let player = Player("Mira")
println(player.label())
```
