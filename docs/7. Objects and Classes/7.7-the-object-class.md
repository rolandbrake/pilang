# 7.7 The Object Class

`Object` is the root prototype for object-like maps. It provides helper methods
for inheritance, identity, comparison, metadata, property access, iteration, and
locking.

Many helpers can be called in either style:

```pilang
obj.method(arg)
Object.method(obj, arg)
```

## Identity and Comparison

- `equals(other)` / `Object.equals(left, right)`: value equality
- `ident(other)` / `Object.ident(left, right)`: object identity
- `compare(other)` / `Object.compare(left, right)`: comparison result
- `hash()`: hash based on the object address

```pilang
let a = { name: "Ada" }
let b = { name: "Ada" }

println(a.equals(b))
println(a.ident(b))
println(Object.compare(a, b))
println(a.hash())
```

## Type and Name

- `type()` / `Object.type(value)`: returns the runtime type
- `name()` / `Object.name(obj)`: returns the intrinsic object name or `nil`
- `setName(name)` / `Object.setName(obj, name)`: sets the intrinsic object name

```pilang
let user = { name: "Ada" }

Object.setName(user, "User")
println(Object.name(user)) // User
println(user.type())       // Object
```

Class declarations set the class name automatically.

```pilang
class Dog {
}

println(Object.name(Dog)) // Dog
```

## Properties

- `get(key)` / `Object.get(obj, key)`: reads a property
- `set(key, value)` / `Object.set(obj, key, value)`: writes a property
- `has(key)` / `Object.has(obj, key)`: checks whether a property exists
- `delete(key)` / `Object.delete(obj, key)`: removes a property
- `keys()`: returns own keys
- `values()`: returns own values

```pilang
let user = {
    name: "Ada",
    age: 36,
}

println(user.has("name"))
println(user.get("age"))

user.set("role", "admin")
println(user.keys())

user.delete("role")
```

Property lookup follows the prototype chain. Setting a new key on a locked object
raises an error.

## Inheritance

- `extends(parent)` / `Object.extends(parent, child)`: sets the parent prototype

```pilang
let Base = {
    tag: "base"
}

let User = Object.extends(Base, {
    name: "Ada"
})

println(User.tag)
```

`Object.extends(parent, child)` returns the child object after linking it.

## Locking

- `lock(value = true)` / `Object.lock(obj, value = true)`: enables or disables
  locked mode

Locked objects cannot add new keys, but existing keys can still be updated.

```pilang
class Settings {
    mode = "dev"
}

Settings.mode = "prod"

Object.lock(Settings, false)
Settings.extra = true
```

## Bracket Access

- `bracketAccess(value = true)` / `Object.bracketAccess(obj, value = true)`:
  enables or disables string-key bracket member access

```pilang
class List {
    format() {
        return "list"
    }
}

Object.bracketAccess(List, true)
println(List["format"]())
```

Dot access is not disabled by `bracketAccess(false)`.

## Iteration

- `iterator()` / `Object.iterator(value)`: resets and returns an iterator target
- `next()` / `Object.next(value)`: returns the next item or `nil`

```pilang
let user = {
    name: "Ada",
    age: 36,
}

let it = user.iterator()
println(it.next())
println(it.next())
println(it.next()) // nil when finished
```

## Cloning and Formatting

- `clone()`: copies an object-like map
- `format()`: returns a formatted string representation

```pilang
let copy = user.clone()
println(copy.format())
```
