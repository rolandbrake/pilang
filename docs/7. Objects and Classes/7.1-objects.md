# 7.1 Objects and Instances

In Pilang, a class and an instance are object values managed by the class
runtime. They are separate from primitive maps.

```swift
class User {
    constructor(name) {
        this.name = name
    }

    greet() {
        return "Hello, " + this.name
    }
}

let user = User("Ada")
println(user.name)
println(user.greet())
```

## Fields

Fields store values by name.

```swift
let point = {
    x: 2,
    y: 4,
}

println(point.x)      // 2
println(point["y"])   // 4
```

Dot access is the normal style for string-like property names. Bracket access is
useful when the key is computed.

```swift
let key = "x"
println(point[key])
```

## Methods

A method is declared inside a class. When called through an instance, it is bound
to `this`.

```swift
class Counter {
    constructor() {
        this.value = 0
    }

    inc() {
        this.value = this.value + 1
        return this.value
    }
}

let counter = Counter()
println(counter.inc()) // 1
println(counter.inc()) // 2
```

## Classes and Instances

`User` is a class value and `user` is an instance created by calling that class.
The instance stores its own fields, while methods are resolved from its class
and inherited classes.

Class values and class instances have distinct runtime types:

```swift
class Point {
    constructor(x, y) {
        this.x = x
        this.y = y
    }
}

let point = Point(2, 4)

println(type(Point)) // class
println(type(point)) // instance
```

## `this`

Inside a method or constructor, `this` is the current receiver.

```swift
class Box {
    constructor(value) {
        this.value = value
    }

    get() {
        return this.value
    }
}

let box = Box(10)
println(box.get()) // 10
```

## Callable Instances

An instance can be called like a function if it defines a `call` method.

```swift
class Counter {
    constructor() {
        this.count = 0
    }

    call() {
        this.count = this.count + 1
        return this.count
    }
}

let counter = Counter()
println(counter()) // 1
println(counter()) // 2
```

Arguments are forwarded to `call`.

```swift
class Adder {
    constructor() {
        this.base = 5
    }

    call(x, y) {
        return x + y + this.base
    }
}

let add = Adder()
println(add(1, 2)) // 8
```

## Object Helpers

Class values and instances provide helper methods through `Object`, including
`get`, `set`, `has`, `delete`, `keys`, `values`, `type`, `name`, `equals`, and
`compare`. Primitive maps support the map collection helpers but are not class
instances.

```swift
println(user.has("name"))
println(user.get("age"))

user.set("active", true)
println(user.keys())
```
