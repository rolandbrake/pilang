# 7.3 Classes

Classes define named runtime types and create class instances.

```swift
class Animal {
    type = "Animal"

    constructor(name) {
        this.name = name
    }

    format() {
        return "Animal(name = " + this.name + ")"
    }
}

let animal = Animal("Milo")
println(animal.format())
```

## Syntax

```swift
class Name {
    staticField = value

    constructor(params) {
        statements
    }

    method(params) {
        statements
    }
}
```

Class bodies use two forms:

- `name = expression` for class/prototype fields
- `name(params) { ... }` for methods

Unlike object literals, class fields use `=` instead of `:`.

## Class Values and Instances

```swift
class Player {
    kind = "player"

    constructor(name) {
        this.name = name
    }
}
```

Class declarations provide:

- the class name is declared by syntax and stored as the object's intrinsic name
- fields use `=`, not `:`
- methods use class method syntax
- inheritance uses `class Child : Parent`
- the class and instance have separate runtime types
- the class is locked after declaration
- string-key bracket access on the class is disabled by default
- the class automatically extends `Object` when no parent is specified

## Class Values

A class declaration creates a value with the class name.

```swift
class Point {
    constructor(x, y) {
        this.x = x
        this.y = y
    }
}

let p = Point(2, 4)
```

The class value is a prototype object. Calling it constructs an instance.

## Class Fields

Fields declared with `=` are stored on the class/prototype object.

```swift
class Dog {
    type = "Dog"

    constructor(name) {
        this.name = name
    }
}

println(Dog.type)
```

Instances can read prototype fields through inheritance.

```swift
let dog = Dog("Buddy")
println(dog.type) // Dog
```

Assigning to an instance field stores the value on that instance.

```swift
dog.type = "Working Dog"

println(dog.type) // Working Dog
println(Dog.type) // Dog
```

## Class Locking

Class prototypes are locked after declaration. Existing fields can be changed,
but adding new fields requires unlocking first.

```swift
class Settings {
    mode = "dev"
}

Settings.mode = "prod"

Object.lock(Settings, false)
Settings.extra = true
```

Object literals are more flexible by default; classes are stricter.

## Bracket Access on Classes

Class prototypes disable string-key bracket member access by default.

```swift
class List {
    format() {
        return "list"
    }
}

println(List.format())

Object.bracketAccess(List, true)
println(List["format"]())
```

Dot access still works even when bracket member access is disabled.

## Inheritance

Use `:` to extend another class.

```swift
class Dog : Animal {
    constructor(name, age) {
        super.constructor(name)
        this.age = age
    }

    format() {
        return "Dog(name = " + this.name + ", age = " + this.age + ")"
    }
}
```

If no parent is specified, the class extends `Object`.

See [Inheritance](7.6-inheritance.md) for `super` and prototype details.
