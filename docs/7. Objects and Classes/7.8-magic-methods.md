# 7.8 Magic Methods

Magic methods are specially named methods that Pilang calls automatically for
object behavior such as formatting, comparison, indexing, calls, and operators.

## Overview

| Method | Used for |
| --- | --- |
| `constructor(...)` | initialize a new instance |
| `format()` | string formatting and display |
| `call(...)` | calling an instance like a function |
| `equals(other)` | `==` and `!=` comparisons |
| `compare(other)` | ordering comparisons such as `<`, `>`, `<=`, `>=` |
| `compute(op, other)` | binary arithmetic and operator overloads |
| `rcompute(op, other)` | reflected binary arithmetic when the object is the right operand |
| `compute(op)` | unary operator overloads |
| `getItem(index)` | custom bracket reads for non-string keys |
| `setItem(index, value)` | custom bracket writes for non-string keys |
| `slice(start, end, step)` | custom slicing |

## `format`

`format()` controls how an object becomes a string for display or string
concatenation.

```swift
class Point {
    constructor(x, y) {
        this.x = x
        this.y = y
    }

    format() {
        return "(" + this.x + ", " + this.y + ")"
    }
}

let point = Point(1, 2)
println(point)
println("point=" + point)
```

## `call`

`call(...)` makes an instance callable.

```swift
class Multiplier {
    constructor(factor) {
        this.factor = factor
    }

    call(value) {
        return value * this.factor
    }
}

let triple = Multiplier(3)
println(triple(10)) // 30
```

## `equals` and `compare`

`equals(other)` customizes equality. `compare(other)` customizes ordering.

```swift
let Box = {
    constructor(value) {
        this.value = value
    },
    equals(other) {
        return is_num(other) && this.value == other
    },
    compare(other) {
        return this.value - other
    }
}

let box = Box(10)

println(box == 10)
println(box > 8)
```

For equality and comparison, Pilang can try object behavior from either side of
the operator.

## `compute`

`compute(op, other)` customizes arithmetic-style binary operators. The `op`
argument is an operator code. Import `lang` to use the named operator constants.

```swift
import lang

class Point {
    constructor(x, y) {
        this.x = x
        this.y = y
    }

    compute(op, other) {
        if op == lang.OP_ADD {
            return Point(this.x + other, this.y + other)
        }

        error("unsupported operator: " + op)
    }

    format() {
        return "(" + this.x + ", " + this.y + ")"
    }
}

let point = Point(1, 2)
println(point + 3)
```

Unary operators call `compute` with a unary operator code. See
[Operator Overloading](../4.%20Operators/4.6-operator-overloading.md) for the
operator-code table and detailed dispatch rules.

Use `rcompute(op, other)` for binary operators where the instance appears on
the right side. For example, `5 - point` calls `point.rcompute(lang.OP_SUB, 5)`.
This method should implement the reversed meaning explicitly for operators such
as `-`, `/`, `%`, exponentiation, and shifts.

## `getItem` and `setItem`

`getItem(index)` handles bracket reads for object instances when the key is not a
string. `setItem(index, value)` handles bracket writes for non-string keys.

```swift
class Box {
    constructor(values) {
        this.values = values
    }

    getItem(index) {
        return this.values[index]
    }

    setItem(index, value) {
        this.values[index] = value
    }
}

let box = Box([10, 20, 30])

println(box[1]) // 20
box[2] = 99
println(box[2]) // 99
```

String keys use normal property lookup. For example, `obj["name"]` reads the
`name` field when bracket access is enabled instead of calling
`getItem("name")`.

## `slice`

`slice(start, end, step)` handles slicing for object instances.

```swift
class ListBox {
    constructor(items) {
        this.items = items
    }

    slice(start, end, step) {
        return this.items[start:end:step]
    }
}

let list = ListBox([10, 20, 30, 40, 50])
println(list[1:4:2])
```

## Built-in Object Methods vs Magic Methods

Methods such as `get`, `set`, `has`, `delete`, `keys`, `values`, `lock`,
`bracketAccess`, `type`, and `name` are built-in object helpers. They are normal
methods inherited from `Object`, not operator hooks.

Magic methods are ordinary methods with names the runtime knows to call in
specific situations.
