# 7.5 Methods

Methods are functions stored on objects, prototypes, or classes. When a method is
called through an object, Pilang binds `this` to the receiver.

```pilang
class Counter {
    constructor(start = 0) {
        this.count = start
    }

    inc() {
        this.count = this.count + 1
        return this.count
    }
}

let counter = Counter()
println(counter.inc()) // 1
```

## Method Syntax

In classes:

```pilang
class TypeName {
    method(a, b) {
        return a + b
    }
}
```

In object literals:

```pilang
let value = {
    method(a, b) {
        return a + b
    }
}
```

## `this`

`this` refers to the current receiver.

```pilang
let user = {
    name: "Ada",
    rename(name) {
        this.name = name
    }
}

user.rename("Grace")
println(user.name) // Grace
```

## Method Arguments

Methods support the same argument rules as functions:

- positional arguments
- default parameters
- named arguments
- `args`
- `kw_args`

```pilang
class Logger {
    write(message, level = "info") {
        println(level + ": " + message)
        println(args)
        println(kw_args)
    }
}

let logger = Logger()
logger.write("saved", level = "debug", tag = "db")
```

## Methods as Values

Reading a method from an instance produces a callable value bound to that
instance.

```pilang
let inc = counter.inc

println(inc())
println(inc())
```

The bound method keeps using the original receiver.

## Prototype Methods

Methods are usually stored on the prototype or class and shared by instances.

```pilang
class Point {
    constructor(x, y) {
        this.x = x
        this.y = y
    }

    move(dx, dy) {
        this.x = this.x + dx
        this.y = this.y + dy
    }
}
```

This keeps instance data separate from method definitions.

## Callable Method

If an instance has a `call` method, the instance itself can be called.

```pilang
class Multiplier {
    constructor(factor) {
        this.factor = factor
    }

    call(value) {
        return value * this.factor
    }
}

let double = Multiplier(2)
println(double(10)) // 20
```

## Static-Like Class Methods

Methods on a class/prototype can also be called directly from the class value.

```pilang
class Label {
    format() {
        return "label"
    }
}

println(Label.format())
```

When called this way, `this` is the class/prototype object.
