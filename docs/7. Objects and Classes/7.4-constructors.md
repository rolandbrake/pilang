# 7.4 Constructors

A constructor initializes a new instance when a prototype or class is called.

```pilang
class Point {
    constructor(x = 0, y = 0) {
        this.x = x
        this.y = y
    }
}

let p = Point(3, 4)
println(p.x)
println(p.y)
```

## Object Literal Constructors

Object literals can define constructors with method shorthand.

```pilang
let Point = {
    constructor(x, y) {
        this.x = x
        this.y = y
    }
}

let p = Point(1, 2)
```

For constructor methods, use method shorthand. A plain field named
`constructor:` is reserved.

## Class Constructors

Class constructors use the same method form.

```pilang
class User {
    constructor(name, role = "user") {
        this.name = name
        this.role = role
    }
}
```

Constructors support normal function features: positional arguments, default
parameters, named arguments, `args`, and `kw_args`.

```pilang
class Connection {
    constructor(host, port = 80) {
        this.host = host
        this.port = port
        this.options = kw_args
    }
}

let conn = Connection("localhost", secure = true)
```

## `this` in Constructors

Inside a constructor, `this` is the new instance.

```pilang
class Counter {
    constructor(start = 0) {
        this.count = start
    }
}
```

Use `this.field = value` to store instance state.

## Constructor Return Value

Constructors return `this` automatically.

```pilang
class Empty {
    constructor() {
    }
}

let item = Empty()
```

A bare `return` is allowed and returns `this`.

```pilang
class Guarded {
    constructor(enabled) {
        if !enabled {
            return
        }

        this.enabled = true
    }
}
```

Constructors cannot return an explicit value.

```pilang
class Bad {
    constructor() {
        // Invalid
        return 10
    }
}
```

## Parent Constructors

Use `super(...)` or `super.constructor(...)` to call the parent constructor.

```pilang
class Animal {
    constructor(name) {
        this.name = name
    }
}

class Dog : Animal {
    constructor(name, age) {
        super(name)
        this.age = age
    }
}
```

Both forms are supported:

```pilang
super(name)
super.constructor(name)
```
