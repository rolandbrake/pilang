# 7.6 Inheritance

Inheritance links one prototype to another. If a field or method is not found on
an object, Pilang looks through its prototype chain.

## Class Inheritance

Use `:` in a class declaration.

```pilang
class Animal {
    constructor(name) {
        this.name = name
    }

    speak() {
        return this.name + " makes a sound"
    }
}

class Dog : Animal {
    speak() {
        return this.name + " says woof"
    }
}

let dog = Dog("Milo")
println(dog.speak())
```

If no parent is written, the class extends `Object`.

## Calling Parent Methods

Use `super` inside methods to access the parent implementation.

```pilang
class Dog : Animal {
    constructor(name, age) {
        super.constructor(name)
        this.age = age
    }

    speak() {
        return super.speak() + ", then barks"
    }
}
```

For constructors, `super(args...)` is shorthand for calling the parent
constructor.

```pilang
class Cat : Animal {
    constructor(name) {
        super(name)
    }
}
```

`super` is only available inside object or class methods.

## Prototype Inheritance

Use `Object.extends(parent, child)` or `child.extends(parent)` to connect object
literals manually.

```pilang
let Animal = {
    kind: "animal",
    speak() {
        return "generic " + this.kind
    }
}

let Dog = Object.extends(Animal, {
    constructor(name) {
        this.name = name
        this.kind = "dog"
    },
    speak() {
        return this.name + " says woof"
    }
})

let dog = Dog("Milo")
println(dog.kind)
println(dog.speak())
```

The parent must be a prototype map, not an instance. The child must also be a
prototype or map literal.

## Lookup Order

When reading `object.name`, Pilang checks:

1. the object's own fields
2. its prototype
3. the prototype's parent
4. eventually `Object`

The first matching key wins.

```pilang
class Base {
    label = "base"
}

class Child : Base {
}

let item = Child()
println(item.label) // base

item.label = "local"
println(item.label) // local
println(Child.label) // base
```

## Inherited Built-ins

Objects inherit built-in methods such as `get`, `set`, `has`, `delete`,
`iterator`, `type`, `name`, and `compare` from `Object`.

```pilang
println(dog.has("name"))
println(dog.type())
```
