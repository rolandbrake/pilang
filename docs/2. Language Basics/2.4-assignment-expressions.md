# 2.4 Assignment Expressions

Assignment is part of Pilang's expression grammar. This lets assignments appear where an expression is expected, and it also enables chained assignment.

```pilang
let a;
let b;

a = b = 0;
```

In the example above, `0` is assigned to `b`, then the same value is assigned to `a`.

## Chained Assignment

Chained assignment is useful when several variables should start with the same value.

```pilang
let x, y, z;
x = y = z = 1;
```

Keep chains short. Long assignment chains are harder to read than separate statements.

## Assignment In Statements

Most assignment expressions are used as statements.

```pilang
let total = 0;
total += 10;
```

The assigned value remains available to the assignment expression internally, but plain expression statements discard their result outside REPL-style evaluation.

## Valid Targets

The left side must be assignable.

```pilang
let name;
let items = [];
let object = {};

name = "Pilang";
items[0] = "first";
object.field = 42;
```

This is invalid because the left side is not a storage location:

```pilang
// Invalid
1 + 2 = value;
```
