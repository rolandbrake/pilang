# 2.7 Comments

Comments are ignored by the parser. Use them to explain intent, mark sections, or temporarily disable code.

## Line Comments

Line comments start with `//` and continue to the end of the line.

```pilang
// This is a line comment.
let total = 0; // This explains one statement.
```

## Block Comments

Block comments start with `/*` and end with `*/`.

```pilang
/*
This comment can span
multiple lines.
*/
let value = 42;
```

An unclosed block comment is a lexer error.

## Comment Style

Prefer comments that explain why code exists or clarify a non-obvious choice.

```pilang
// Wrap around when the pointer reaches the end of memory.
if ptr == length - 1 {
    ptr = 0;
}
```

Avoid comments that only repeat the code.

```pilang
// Set count to 1.
count = 1;
```
