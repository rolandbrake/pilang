# 2.3 Assignment

Assignment stores a new value in an existing variable or assignable target.

```pilang
let count = 0;
count = 1;
```

## Simple Assignment

Use `=` to replace the value.

```pilang
let message = "hello";
message = "goodbye";
```

Assignments can target variables, list elements, map entries, and object fields.

```pilang
let items = [10, 20, 30];
items[1] = 99;

let user = {};
user.name = "Ada";
user["active"] = true;
```

## Multiple Assignment

Use a list-style target on the left side to assign several names from one
right-hand value.

```pilang
[a, b] = [10, 20];

println(a); // 10
println(b); // 20
```

This is useful when a function returns a list of related values.

```pilang
fun pair(left, right) {
    return [left, right];
}

[first, second] = pair("x", "y");

println(first);  // x
println(second); // y
```

The brackets on the left side are an assignment target, not a list being
created. Pilang reads items from the right-hand value and stores them into the
names on the left in order.

```pilang
[name, score] = ["Ada", 95];
```

The left side must contain names that can be assigned. This form is often called
destructuring assignment because it breaks a list-like result into separate
variables.

## Compound Assignment

Compound assignment reads the current value, applies an operator, and stores the result.

```pilang
let n = 10;
n += 5;  // 15
n -= 2;  // 13
n *= 3;  // 39
n /= 3;  // 13
n %= 5;  // 3
```

Bitwise compound assignments are also available.

```pilang
let flags = 0;
let mask = 3;
let toggle = 2;

flags |= 1;
flags &= mask;
flags ^= toggle;
```

## Increment And Decrement

Use `++` and `--` to increase or decrease a numeric target by one.

```pilang
let i = 0;
i++;
i--;
```

These forms are commonly used in loops and indexing code.
