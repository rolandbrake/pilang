# 2.2 Constants

Pilang has constant literal values and built-in constants, but the current language does not expose a separate `const` declaration keyword. Use `let` for named values and avoid reassigning names that you intend to treat as constants.

```pilang
let PI_APPROX = 3.14159;
let MAX_ITEMS = 100;
```

## Literal Constants

These values are built into the language syntax:

```pilang
true;
false;
nil;
INF;
NAN;
```

- `true` and `false` are boolean values.
- `nil` represents the absence of a value.
- `INF` represents infinity.
- `NAN` represents "not a number".

## Module Constants

Some built-in modules also provide constants. For example, math, system, OS, drawing, and language modules may define named values that should be treated as read-only API values.

```pilang
import math;

println(math.PI);
println(math.E);
```

## Convention

When a `let` binding is meant to behave like a constant, use an uppercase name.

```pilang
let DEFAULT_TIMEOUT = 30;
```
