# 2.5 Expressions

An expression is code that produces a value. Expressions are used in assignments, function calls, conditionals, loops, list items, map values, and return statements.

## Statement Endings

Semicolons are optional at the end of most lines. A newline can separate statements.

```pilang
let x = 1
let y = 2
println(x + y)
```

You can still use semicolons when you want a more explicit delimiter or when writing multiple statements close together.

```pilang
let x = 1; let y = 2;
println(x + y);
```

## Literal Expressions

```pilang
42;
3.14;
"hello";
true;
false;
nil;
[1, 2, 3];
{"name": "Pilang"};
```

## Variable And Access Expressions

```pilang
let name = "Pilang";
let items = [10, 20, 30, 40];
let user = {};
import math;

name;
items[0];
items[1:3];
user.name;
math.PI;
```

## Operator Expressions

```pilang
let count = 10;
let ready = true;
let enabled = false;
let value = 2;
let values = [1, 2, 3];

1 + 2 * 3;
(1 + 2) * 3;
count >= 10;
ready && enabled;
value in values;
```

Pilang follows operator precedence rules, so multiplication binds more tightly than addition. Use parentheses when grouping matters or when they make intent clearer.

## Conditional Expressions

Pilang supports a ternary-style conditional expression.

```pilang
let label;
let score = 75;

label = score >= 60 ? "pass" : "fail";
```

## Function Call Expressions

Function calls are expressions too.

```pilang
println("hello");
fun factorial(n = 0) {
    if n <= 1
        return 1;
    return n * factorial(n - 1);
}

answer = factorial(5);
```

## Ranges And Slices

Ranges are expressions and are often used in `for` loops.

```pilang
1..10;
0..100:5;
```

Slices use bracket access.

```pilang
let items = [10, 20, 30, 40, 50];

items[:3];
items[3:];
items[1:4];
```
