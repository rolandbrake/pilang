# 6.2 Anonymous Functions

Anonymous functions are function values created without a declaration name. They
use the `fun` keyword followed directly by a parameter list and a block body.

```pilang
let add = fun(a, b) {
    return a + b
}

println(add(2, 3)) // 5
```

## Syntax

```pilang
fun(parameter1, parameter2, ...) {
    statements
}
```

Anonymous functions are expressions. They can be assigned to variables, stored in
lists or maps, passed to other functions, or returned from functions.

```pilang
let operations = [
    fun(n) { return n + 1 },
    fun(n) { return n * 2 },
]

println(operations[0](10)) // 11
println(operations[1](10)) // 20
```

## Passing Anonymous Functions

Anonymous functions are useful when an operation is only needed in one place.

```pilang
let numbers = [1, 2, 3, 4]

let doubled = map(numbers, fun(n) {
    return n * 2
})

println(doubled) // [2, 4, 6, 8]
```

## Returning Anonymous Functions

Because functions are values, a function can return another function.

```pilang
fun make_multiplier(amount) {
    return fun(value) {
        return value * amount
    }
}

let triple = make_multiplier(3)
println(triple(10)) // 30
```

The returned anonymous function keeps access to `amount`; this is a closure.

## Implicit `nil`

Anonymous functions follow the same return rules as named functions. If control
reaches the end of the body without a `return`, the result is `nil`.

```pilang
let log = fun(message) {
    println(message)
}

println(log("done")) // nil
```

## Recursive Anonymous Functions

An anonymous function assigned to a variable can call itself through that
variable.

```pilang
let factorial = fun(n) {
    if n <= 1 {
        return 1
    }

    return n * factorial(n - 1)
}

println(factorial(5)) // 120
```

For shorter expression-style functions, see [Arrow Functions](6.3-arrow-functions.md).
