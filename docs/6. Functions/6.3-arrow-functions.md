# 6.3 Arrow Functions

Arrow functions are compact function expressions. They are useful for short
callbacks, transformations, predicates, and small helper functions.

## Expression Body

An expression-body arrow returns the expression automatically.

```pilang
let square = x -> x * x

println(square(6)) // 36
```

For more than one parameter, wrap the parameter list in parentheses.

```pilang
let add = (a, b) -> a + b

println(add(2, 3)) // 5
```

For zero parameters, use an empty parameter list.

```pilang
let answer = () -> 42

println(answer()) // 42
```

## Block Body

An arrow function can also use a block body.

```pilang
let clamp_positive = n -> {
    if n < 0 {
        return 0
    }

    return n
}
```

Block-body arrows use normal function return rules. They need an explicit
`return` to return a non-`nil` value.

```pilang
let log = message -> {
    println(message)
}

println(log("saved")) // nil
```

## Common Uses

Arrow functions pair well with functional helpers.

```pilang
let numbers = [1, 2, 3, 4, 5]

let evens = filter(numbers, n -> n % 2 == 0)
let squares = map(evens, n -> n * n)

println(squares) // [4, 16]
```

They can also be used for simple closures.

```pilang
fun make_adder(amount) {
    return value -> value + amount
}

let add10 = make_adder(10)
println(add10(5)) // 15
```

## Parameter Forms

```pilang
let one = x -> x + 1
let two = (x, y) -> x + y
let none = () -> "ready"
```

Single-parameter arrows do not need parentheses. Multi-parameter and
zero-parameter arrows do.

## Arrow Functions vs `fun`

Use arrow functions when the function is small and reads naturally inline. Use
`fun` when the body is longer, needs several statements, or benefits from a clear
declaration shape.

```pilang
let short = n -> n * 2

let longer = fun(n) {
    let result = n * 2
    println(result)
    return result
}
```
