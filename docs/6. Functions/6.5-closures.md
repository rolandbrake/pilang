# 6.5 Closures

A closure is a function that keeps access to variables from the scope where it
was created, even after that outer scope has returned.

```swift
fun make_counter() {
    let i = 0

    fun count() {
        i = i + 1
        return i
    }

    return count
}

let counter = make_counter()

println(counter()) // 1
println(counter()) // 2
println(counter()) // 3
```

The inner `count` function captures `i`. Each call updates the same captured
variable.

## Capturing Values

Closures can read captured variables.

```swift
fun make_greeter(prefix) {
    return name -> prefix + ", " + name
}

let hello = make_greeter("Hello")
println(hello("Pilang")) // Hello, Pilang
```

They can also update captured variables.

```swift
fun make_accumulator(start = 0) {
    let total = start

    return amount -> {
        total = total + amount
        return total
    }
}

let add = make_accumulator(10)
println(add(5)) // 15
println(add(2)) // 17
```

## Independent Closure State

Each call that creates a closure gets its own captured variables.

```swift
let a = make_counter()
let b = make_counter()

println(a()) // 1
println(a()) // 2
println(b()) // 1
```

## Closures and Scope

Closures follow normal scope rules. A function first looks for a local variable,
then captured variables, then module/global names.

```swift
let label = "global"

fun make_labeler(label) {
    return () -> label
}

let local_label = make_labeler("local")
println(local_label()) // local
```

Remember the variable rule from [Variables](../2.%20Language%20Basics/2.1-variables.md):
assigning to a new name in a local scope without a declaration creates or
updates a module/global variable. Use `let` or `const` when you want a new local
binding to be captured by a closure.

```swift
fun make_safe_counter() {
    let count = 0

    return () -> {
        count = count + 1
        return count
    }
}
```

## Common Uses

Closures are useful for:

- remembering state between calls
- creating specialized functions
- callbacks that need configuration
- functional pipelines
- private helper state inside a larger function

```swift
fun above(limit) {
    return value -> value > limit
}

let high_scores = filter([4, 8, 15, 16, 23, 42], above(10))
println(high_scores) // [15, 16, 23, 42]
```
