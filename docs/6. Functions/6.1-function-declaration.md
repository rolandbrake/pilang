# 6.1 Function Declaration

Named functions are declared with the `fun` keyword, followed by the function
name, a parameter list, and a block body.

```swift
fun greet(name) {
    println("Hello, " + name)
}

greet("Pilang")
```

## Syntax

```swift
fun name(parameter1, parameter2, ...) {
    statements
}
```

The body of a named function is always a block enclosed in `{}`.

```swift
fun add(a, b) {
    return a + b
}

println(add(2, 3)) // 5
```

## Returning Values

Use `return` to leave the function and send a value back to the caller.

```swift
fun square(n) {
    return n * n
}

let result = square(6)
println(result) // 36
```

If a function does not execute a `return`, it returns `nil`.

```swift
fun log_message(message) {
    println(message)
}

let value = log_message("saved")
println(value) // nil
```

A bare `return` also returns `nil`.

```swift
fun stop_early(flag) {
    if flag {
        return
    }

    println("still running")
}
```

Because newlines can end statements, put a returned expression on the same line
as `return`.

```swift
fun good() {
    return 10
}

fun returns_nil() {
    return
    10
}
```

## Parameters

Parameters are local variables created for each call.

```swift
fun describe(name, age) {
    println(name + " is " + age)
}

describe("Ada", 36)
```

The number of declared parameters is the function's declared arity.

```swift
fun move(x, y, speed = 1) {
    println(x)
    println(y)
    println(speed)
}
```

`move` has an arity of `3` because it declares three parameters. Pilang allows up
to 32 declared parameters.

Function calls are flexible:

- positional arguments are assigned from left to right
- missing arguments use their default value
- missing arguments without a default become `nil`
- extra positional arguments are not bound to named parameters, but they still
  appear in `args`
- named arguments are matched to parameters by name
- unknown named arguments are still available in `kw_args`
- passing the same parameter positionally and by name is an error

## Default Parameters

Parameters can define default values with `=`.

```swift
fun repeat_text(text, times = 1) {
    let output = ""

    for i in 0..times {
        output = output + text
    }

    return output
}

println(repeat_text("ha"))     // ha
println(repeat_text("ha", 3))  // hahaha
```

Default values are used when the caller does not provide that argument.

## Named Arguments

Named arguments use `name = value` in a function call. They are matched against
the function's parameter names, so the caller can skip or reorder optional
arguments.

```swift
fun connect(host, port = 80, secure = false) {
    println(host)
    println(port)
    println(secure)
}

connect("localhost", secure = true)
```

In this call:

- `host` is filled by the positional argument `"localhost"`
- `port` is not provided, so it uses the default `80`
- `secure` is filled by the named argument `secure = true`

Once a named argument appears, all later arguments in the same call must also be
named.

```swift
connect("localhost", secure = true)

// Invalid: positional argument after a named argument
connect(host = "localhost", 8080)
```

If a parameter receives both a positional value and a named value, Pilang raises
an error.

```swift
// Invalid: port gets both 8080 and 3000
connect("localhost", 8080, port = 3000)
```

## `args` and `kw_args`

Every function has two automatic local variables:

- `args`: a list of positional arguments passed to the call
- `kw_args`: a map of named arguments passed to the call

```swift
fun inspect(a, b = nil) {
    println(a)
    println(b)
    println(args)
    println(kw_args)
}

inspect(10, mode = "fast")
```

In this example:

- `a` receives `10`
- `b` becomes `nil`
- `args` contains the positional arguments
- `kw_args` contains `{ "mode": "fast" }`

This is useful for forwarding calls, debugging call shapes, and writing flexible
helpers that accept optional named settings.

## Function Scope

Functions declared at the top level become module/global symbols.

```swift
fun version() {
    return "1.0"
}
```

Functions declared inside another local scope are local to that scope.

```swift
fun outer() {
    fun inner() {
        return "inside"
    }

    return inner()
}

println(outer()) // inside
```

Named local functions can call themselves recursively because the name is
available inside the function body.

```swift
fun factorial(n) {
    if n <= 1 {
        return 1
    }

    return n * factorial(n - 1)
}
```

## Functions Are Values

A function name evaluates to the function value, so it can be assigned or passed
around.

```swift
fun double(n) {
    return n * 2
}

let operation = double
println(operation(5)) // 10
```

## Call Result

A function call is an expression. You can use it wherever a value is expected.

```swift
let total = add(4, 5) * 2
println(total) // 18
```
